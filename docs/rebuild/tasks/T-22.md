# T-22 ホーム＋タグ検索

あなたはモック再現に強いフロントエンドエンジニアです。対象：ホーム（`/`）と資材検索（`/search`）。見た目の正はモックの home / search 画面（`docs/rebuild/reference/screens/home.txt`・`search.txt`＋ブラウザで `docs/rebuild/reference/mockup-sp-19screens.html`）。仕様は `docs/rebuild/02-screens.md` §2。

## 制約

- 触ってよいのは `frontend/src/app/page.tsx`（差し替え）・`frontend/src/app/search/`（新規）・`frontend/src/components/search/`（検索専用部品）・`frontend/src/server/queries/`（必要な追加関数のみ。既存関数のシグネチャ変更禁止）
- T-21 の共通コンポーネント（components/）を必ず使う。無いものだけ新設し、汎用性があれば components/ へ、検索専用なら components/search/ へ
- データは server 層経由（`src/server/queries/materials.ts` の listMaterials 等）。UI から supabase 直呼び禁止。ダミーデータのハードコード禁止（ローカルシード15件が表示データ）
- UI 用語は「レビュー」「使用レポート」（D8）

## 実装

1. **ホーム `/`**：hero 見出し「農業の未来を、みんなの知恵で。」＋リード（「口コミ」→「レビュー」に置換した文言）→ 検索ボックス＋候補チップ（よく探されている条件＝POPULAR 相当・今の時期におすすめ＝SEASONAL 相当。タグシードから category で取得）→ 注目のBS資材（レビュー数上位3件・横スクロール・カードは実データの material.id へリンク）→ 新着の使用レポート（published 上位・無ければセクション非表示）→ 新着レビュー（アンカー付きで資材詳細へ）→ 未ログイン時のみ登録 CTA
2. **検索 `/search`**：タグ選択 UI（オートコンプリート・チップ・**同一分類 OR・分類間 AND**。選択状態は URL クエリ `?tags=` に反映して共有可能に）→ 絞り込み条件の文言表示（「ミニトマト または いちご かつ 高温対策」形式）→ 件数＋並び替え（レビューが多い順／評価が高い順／新着順を**実装**）→ 結果リスト（各カードは該当資材へ）
3. 検索ロジックはサーバー側（listMaterials を拡張してよい：sort パラメータ追加等）。タグ候補の取得もサーバー経由
4. ローディング・空結果の状態（EmptyState 使用）

## 検証（完了条件）

```bash
cd frontend && pnpm lint && pnpm format:check && pnpm exec tsc --noEmit && pnpm exec vitest run && pnpm build
```

ローカルスタック起動（`npx supabase start -x studio,analytics,vector,edge-runtime,functions,inbucket,imgproxy,realtime`）＋シード投入（`tools/migration/README.md` の手順で15件）で `pnpm dev` を起動し、**375px 幅**で：タグ2分類選択で AND/OR が効く・並び替えが変わる・カードから資材詳細 URL（404 で可＝T-23 未実装）へ遷移する、をログ・スクリーンショットで確認。終了時 `npx supabase stop --no-backup`。
