# T-22 ホーム検索入口＋資材分類検索

あなたはモック再現に強いフロントエンドエンジニアです。対象：ホーム（`/`）と資材検索（`/search`）。見た目の正はモックの home / search 画面（`docs/rebuild/reference/screens/home.txt`・`search.txt`＋ブラウザで `docs/rebuild/reference/mockup-sp-19screens.html`）。仕様は `docs/rebuild/02-screens.md` §2。

## 制約

- 触ってよいのは `src/app/page.tsx`（差し替え）・`src/app/search/`（新規）・`src/components/search/`（検索専用部品）・`src/server/queries/`（必要な追加関数のみ。既存関数のシグネチャ変更禁止）・`panda.config.ts`（下記トークン追加のみ）・`src/components/` の TagChip（分類色の実値化のみ）
- **最初に panda.config.ts へ追加**（T-21 報告のモック実値）：`colors.tag.concern=#D97A2B`・`tag.effect=#1F9E95`・`tag.type=#8B7BC0`・`tag.name=#C0705F`・`danger=#C0392B`・`danger.soft=#FDECEC`。追加後、TagChip の近似色を実値トークンへ置換
- T-21 の共通コンポーネント（components/）を必ず使う。無いものだけ新設し、汎用性があれば components/ へ、検索専用なら components/search/ へ
- データは server 層経由（`src/server/queries/materials.ts` の listMaterials 等）。UI から supabase 直呼び禁止。ダミーデータのハードコード禁止（ローカルシード15件が表示データ）
- UI 用語は「レビュー」「使用レポート」（D8）

## 実装

1. **ホーム `/`**：既存のhero・注目資材・新着使用レポート・新着レビュー・登録CTAは維持し、「資材を検索する（作物・悩み・資材名から）」と「検索へ →」を含む単一リンクだけを置く。候補や条件チップはホームで展開しない
2. **公開ヘッダー**：モバイルはFarmilleロゴと検索アイコン。PCはFarmilleロゴ、使用レポート一覧、資材検索入口、投稿、マイページの順に常設する
3. **検索 `/search`**：効果・作物・製品タイプ・悩み・栽培条件の選択UI（オートコンプリート・チップ・**同一分類 OR・分類間 AND**。選択状態はURLクエリ `?filters=` に分類接頭辞付きで反映）→ 絞り込み条件の文言表示（「ミニトマト または いちご かつ 高温対策」形式）→ 件数＋並び替え（レビューが多い順／評価が高い順／新着順）→ 結果リスト
4. 検索ロジックと候補取得はサーバー層へ置く
5. ローディング・空結果の状態（EmptyState 使用）

## 検証（完了条件）

```bash
pnpm lint && pnpm format:check && pnpm exec tsc --noEmit && pnpm exec vitest run && pnpm build
```

ローカルスタック起動＋シード投入後に `pnpm dev` を起動し、**375px幅**で：ホームの検索入口とヘッダー検索から `/search` へ遷移する・2分類選択でAND/ORが効く・並び替えが変わる・カードから資材詳細へ遷移する、をログ・スクリーンショットで確認。
