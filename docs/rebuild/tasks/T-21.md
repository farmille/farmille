# T-21 共通 UI キット（モック忠実再現・Panda recipes）

あなたはピクセル単位の再現に強い UI エンジニアです。モック `docs/rebuild/reference/mockup-sp-19screens.html`（ブラウザで直接開ける）と画面別抽出 `docs/rebuild/reference/screens/*.txt` を参照し、全画面で使う共通コンポーネントを作る。**このキットの出来が M2 以降の全画面の品質を決める。**

## 制約

- 触ってよいのは `src/components/`・`panda.config.ts`（recipe 追加のみ。トークン値の変更禁止）・`src/app/dev/ui/`（新規プレビューページ）
- ページ実装（`src/app/` 配下の実ルート）は作らない
- 色・余白等の生値直書き禁止。T-03 のトークン・semanticTokens を使う。バリアントは recipe で列挙（docs/rebuild/03 §8）
- ダークモード禁止（D12）
- UI 文言は「レビュー」「使用レポート」「対照区」（D8。モックの「口コミ」等は置換して实装）

## 作るもの（モックの対応関数）

| コンポーネント | モック対応 | 要点 |
|---|---|---|
| AppBar | appbar() | home 型（ロゴ＋検索アイコン）／戻る型（＋任意で共有）。sticky |
| BottomNav | NAV | 5枠・中央は丸型＋ボタン。現在地ハイライト。href は /・/search・/post・/articles・/me |
| FabBar | fab-bar | 「使用レポートを書く」（primary）＋「レビューを書く」（ghost）固定バー |
| MaterialCard | matCard/prod-card | 画像・名前・メーカー・★・件数。横スクロール用と一覧用 |
| ReviewCard | reviewCard() | アイコン・ハンドル・作物チップ・★＋数値・本文・参考になった。**閲覧数は出さない**（02 §4-9） |
| ReportCard | reportCard() | 使用レポートのカード（横スクロール・一覧両対応） |
| ArticleCard / ArtMini | orgArticleCard()/artMini() | 組織記事カード・簡易行 |
| TagChip | ts-chips/chip | 分類色（TAG_CATS の色相をトークン化済みの範囲で）・選択状態・×削除 |
| StarRating | ★表示 | 表示用（0.5刻み表示は不要・整数）と入力用（タップで1〜5） |
| StatCard | 実績カード | 大きな緑数字＋ラベル |
| SectionHeading | sec-h | 見出し＋「→」リンク |
| FilterPills | fpill | 記事一覧のフィルタピル |
| Badge | 公式マーク・公開バッジ等 | official（青チェック）・type ラベル・必須/任意 |
| Button / Input / Textarea / Select | btn ほか | primary/ghost/danger・フォーム基本要素 |
| EmptyState | — | 「まだ投稿がありません」等の空状態 |

各コンポーネントは Server Component 前提（インタラクティブなもののみ "use client"）。props は明示的な型（database.types からの派生 DTO を受ける想定だが、このタスクでは表示用の素朴な props 型でよい——結線は各画面タスクの責務）。

## プレビューページ `/dev/ui`

全コンポーネント・全バリアントを一覧表示（/dev/tokens と同様に production では notFound()）。モックのサンプルデータ（Skeepon・やまちゃん農園等）をダミーとして使用。

## 検証（完了条件）

```bash
pnpm lint && pnpm format:check && pnpm exec tsc --noEmit && pnpm exec vitest run && pnpm build
```

`pnpm dev` を起動し、**375px 幅で** `/dev/ui` をモックと並べて目視比較すること。スクリーンショットが撮れる環境なら添付、無理なら skip と明記。

## 質問すべき条件

- モックの見た目とトークン定義が両立しない箇所は、モックを正としてトークン追加が必要なら **panda.config.ts への追加内容を報告に列挙**（勝手に生値で逃げない）

## 最終報告の形式

作成コンポーネント一覧／検証結果／トークン追加・変更の一覧／モックとの意図的な差分（用語置換以外）。
