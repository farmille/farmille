# T-51 Playwright E2E（主要8フロー）

あなたはE2Eテスト設計に長けたエンジニアです。対象：`frontend/e2e/`（新規）＋ Playwright 設定＋ CI 組み込み。

## 制約

- 触ってよいのは `frontend/e2e/`・`frontend/playwright.config.ts`・`frontend/package.json`（scripts と devDeps の追加のみ）・`.github/workflows/`（e2e ジョブ追加）
- テストはローカル Supabase（127.0.0.1:54321）＋ `next start`（本番ビルド）に対して実行。各テストは自分でデータを作り自分で片付ける（他テストへの依存禁止）。既存シード15件は読み取り前提でよい
- admin 作成は `tools/dev/create-local-admin.ts` を setup で利用。TOTP は `otpauth` 等の軽量ライブラリで生成

## 8フロー

1. 一般登録→ログイン→ログアウト（handle 重複エラー含む）
2. レビュー投稿→資材詳細に反映（集計値）→編集→削除
3. 使用レポート下書き→提出（pending で公開側 404）
4. 検索：タグ AND/OR・並び替え・検索結果→詳細遷移
5. 検討リスト保存→ /me/saved →比較表
6. 出品者申請→ admin 承認（MFA enroll→AAL2 込み）→出品者ログイン→ダッシュボード
7. 出品者：一次情報編集→公開反映／記事作成→公開→関連記事表示
8. 通報→ admin で resolve→対象非公開／編集局：pending→公開
- 補助：未ログインの保護ページリダイレクト・`?next=` 細工が `/` に落ちる（safe-next 回帰）
