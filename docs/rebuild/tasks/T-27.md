# T-27 spacing トークン欠落の修正（P0）＋全画面のモック照合撮り直し＋重複除去（P1）

あなたは Panda CSS とデザインシステムに精通したエンジニアです。監査（2026-07-27）で確定した真因を修正し、全画面をモックと2枚並べで照合し直す。監査の証跡は `docs/rebuild/tasks/evidence/audit-*.png`。

## 背景（確定済みの診断・再調査不要）

`frontend/panda.config.ts` が `theme.tokens` を `extend` なしで定義しているため、Panda 既定プリセットの **spacing・lineHeights・fontWeights がグループごと消滅**。数値 spacing トークン（`px="4"` 等・709箇所）が本来の 1/4 の生 px に解決され、キット含む全画面の余白が潰れている。色・角丸・タイポ・影のトークン値は正しい（無罪確定）。

## 制約

- 触ってよいのは `frontend/panda.config.ts`・P1 対象ファイル（下記）・`frontend/src/components/auth/`（px 直値のトークン化のみ）・撮り直しスクリーンショットの `docs/rebuild/tasks/evidence/` への保存
- **`extend` 方式は採らない**（決定済み。プリセット色317件を復活させずパレット封鎖を維持）
- 画面のレイアウト・ロジック変更禁止（P1 の重複除去を除く）。ピクセル単位の個別パッチ禁止

## 手順

1. **P0**：`panda.config.ts` の `theme.tokens` に **spacing（`@pandacss/preset-panda` と同値の71件）・lineHeights・fontWeights** を明示追加（node_modules/@pandacss/preset-panda の dist から値を転記。手打ちで創作しない）。`panda codegen` 再実行で `SpacingToken` 型と spacing 71件が生成されることを確認
2. **P1 重複除去（3件・ロジック温存でビューだけ）**：
   - `src/app/materials/[id]/_components/pagination.tsx` を削除し `src/components/pagination.tsx` を import（監査で「import 順と JSDoc 以外完全一致」確認済み）
   - `src/app/materials/[id]/report/_components/form-ui.tsx` の自前 `SectionHeading` を廃してキット版を使用。`Input`/`Textarea`/`Select` もキット版へ
   - `src/app/materials/[id]/_components/page-shell.tsx` と `src/components/form-page-shell.tsx` の役割重複を解消（キット版に寄せる）
3. **認証系の整合**：`src/components/auth/` の px 直値41箇所を spacing トークンへ換算置換（P0 後は px 直値だけ相対的に浮くため。見た目が変わらないことを撮り比べで確認）
4. **全画面撮り直し（モック2枚並べ・375px）**：`/`・`/search`・`/materials/[id]`（＋reviews）・`/reports/[id]`・`/articles`・`/articles/[id]`・`/sellers/[id]`・`/users/[id]`・`/me`・`/login`・`/signup`・レビュー投稿・使用レポート投稿の各画面と、モックの対応画面（`docs/rebuild/reference/mockup-sp-19screens.html` を file:// で開き上部チップで切替）を**左右2枚並べ**にして `evidence/reskin-<route>-vs-mock.png` として保存。ローカルスタック（127.0.0.1:54321・起動済み）と dev サーバーを使用
5. **判定表を作る**：撮り直し後も残る乖離を画面ごとに「なし／軽微／要対応（P2 候補）」で一覧化（余白起因は P0 で解消しているはずなので、残るのは構成・部品差のはず）
6. 検証・コミット（P0 と P1 はコミットを分ける）

## 検証（完了条件）

pipefail で：lint／format:check／tsc／vitest／build 全成功。`styled-system/tokens` に spacing 71件。配信 CSS から `padding: 3.5px` 等の 1/4 値が消えたことを実測1件以上。ホームの本文ガターが 16px・SectionHeading の上余白が 24px になっていることを computed style で確認。

## 質問すべき条件

- preset の spacing 値転記で疑義が出た場合・page-shell の統合で挙動差が出る場合は該当箇所を保留にして報告

## 最終報告の形式

P0 の差分要約／P1 各件の処理結果／全画面判定表（なし／軽微／要対応）／証跡パス一覧／検証結果。
