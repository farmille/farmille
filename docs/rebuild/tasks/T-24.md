# T-24 記事一覧・記事詳細・使用レポート閲覧（公開側）

あなたはモック再現に強いフロントエンドエンジニアです。対象：`/articles`・`/articles/[id]`・`/reports/[id]`。見た目の正はモックの articles / articleDetail / reportArticle 画面（`docs/rebuild/reference/screens/` の各 txt＋モック HTML）。仕様は `docs/rebuild/02-screens.md` §2。

## 制約

- 触ってよいのは `src/app/articles/`・`src/app/reports/`（いずれも新規）・`src/server/queries/`（追加のみ）・components/ への追加
- T-21 の共通コンポーネント使用・server 層経由・ハードコード禁止・用語は D8（レビュー／使用レポート／対照区）
- FabBar は `/reports/[id]` に表示（02 §2。対象資材への投稿導線）

## 実装

1. **`/articles`**：検索ボックス（タイトル部分一致・**実装する**）＋フィルタピル（すべて／使用レポート／記事）＋カードグリッド。使用レポート（published）と記事（published）を混載し、カードから各詳細へ。ページネーション
2. **`/articles/[id]`**：記事詳細 — タイトル・バイライン（組織ロゴ/名前/種別ラベル/日付。**seller_type を問わず** `/sellers/[id]` へリンク＝モックの sellerJA 孤立の解消）・hero 画像・本文（markdown render。`src/lib/markdown/render.ts` 使用）・「この記事で紹介した資材」カード（article_materials）・参考になった数＋閲覧数表示
3. **`/reports/[id]`**：使用レポート閲覧 — モック reportArticle の構成（タイトル・投稿者バイライン→`/users/[id]`・対象資材カード→`/materials/[id]`・カバー写真/動画・使用目的タグ・環境・使用方法/処理日・気候・観察した変化＋写真・マイナス点・収穫調査（usage_report_metrics から**表示時にバーを生成**。単純な横棒2本の比較で可）・まとめ・農薬非断定の明記・参考になった＋閲覧数）。published のみ。draft/pending は notFound
4. 閲覧イベント：`/reports/[id]`・`/articles/[id]` 表示時に view_events へ記録（Server Action か route。非同期・失敗しても表示は壊さない）
5. generateMetadata（両詳細）

## 検証（完了条件）

ゲート一式＋ローカルスタック（起動が無ければ除外オプション付きで起動・終了時 stop --no-backup）。開発シードに published の記事・使用レポートが無い場合は、**検証用シードを `supabase/seed.sql`（ローカル専用）に追加してよい**（migration には入れない）。375px で3ルートの実表示確認・スクリーンショット。
