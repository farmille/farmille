# T-33 マイページ（3棚）・プロフィール編集・検討リスト・資材比較

あなたはモック再現に強いフロントエンドエンジニアです。対象：`/me`・`/me/edit`・`/me/saved`・`/me/saved/compare`。見た目の正はモックの mypage / profilePublic（`docs/rebuild/reference/screens/mypage.txt` ほか）。仕様は `02-screens.md` §2・§4 と `01-domain-model.md` §3 profiles・saved_materials。

## 制約

- 触ってよいのは `src/app/me/`（新規）・`src/server/`（profiles/saved 系の追加）・components/ への追加
- 一般ユーザー専用（requireGeneralUser。出品者・admin は各ダッシュボードへ誘導文）
- アバターは Storage `avatars`・パス `{user_id}/…`
- server 層経由・トークン経由・用語 D8

## 実装

1. **`/me`**：プロフィールカード（アバター・ハンドル・地域＋公開バッジ・主な作目・栽培形態・所属バッジ（D5）・一言・外部リンク・「プロフィールを編集」）→ 実績（レビュー数・参考になった数）→ **3棚**：自分の投稿（レビュー＋使用レポート。使用レポートは draft／pending／published のステータスバッジ付き・draft はフォーム再開へ）／検討リスト（横スクロール＋「すべて見る」→ /me/saved）／参考になったを付けた一覧。ログアウトボタン（POST /logout）と「出品者の方はこちら」（/sellers/apply）導線もここに置く
2. **`/me/edit`**：登録項目＋任意項目の編集（ハンドル・都道府県＋公開トグル・一言・主な作目（複数選択）・栽培形態・所属（任意 text）・website/sns・アバターアップロード）。standpoint は**編集不可・表示もしない**（内部専用）。ハンドル重複はフィールドエラー
3. **`/me/saved`**：保存資材一覧（解除ボタン付き）＋2〜4件選択して「比較する」
4. **`/me/saved/compare`**：選択資材の比較表（名前・メーカー・平均★・レビュー数・対照区あり率・製品タイプ・主なタグ・価格帯）。横スクロールの簡易表でよい（02 §2）
5. 空状態（保存0件・投稿0件）の文言

## 検証（完了条件）

ゲート一式（pipefail で終了コードを正確に）＋実フロー：signup→プロフィール編集（アバター含む）→公開プロフィール（/users/[id]）に反映・非公開切替で地域が消える→資材保存→/me/saved→2件比較。375px スクリーンショット（/me・edit・compare）。

## 質問すべき条件

- profiles にカラム不足があれば停止して報告（スキーマ変更は別タスク）
