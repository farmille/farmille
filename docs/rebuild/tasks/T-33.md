# T-33 マイページ（3棚）・表示情報編集・検討リスト・資材比較

あなたはモック再現に強いフロントエンドエンジニアです。対象：`/me`・`/me/edit`・`/me/saved`・`/me/saved/compare`。見た目の正はモックの mypage / profilePublic（`docs/rebuild/reference/screens/mypage.txt` ほか）。仕様は `02-screens.md` §2・§4 と `01-domain-model.md` §3 profiles・saved_materials。

## 制約

- 触ってよいのは `src/app/me/`（新規）・`src/server/`（profiles/saved 系の追加）・components/ への追加
- 一般ユーザー専用（requireGeneralUser。メーカー・admin は各ダッシュボードへ誘導文）
- アバターは Storage `avatars`・パス `{user_id}/…`
- server 層経由・トークン経由・用語 D8

## 実装

1. **`/me`**：表示情報カード（アバター・ハンドル・「表示情報を編集」）→ 実績（レビュー数・参考になった数）→ **3棚**：自分の投稿（レビュー＋使用レポート。使用レポートは draft／pending／published のステータスバッジ付き・draft はフォーム再開へ）／検討リスト（横スクロール＋「すべて見る」→ /me/saved）／参考になったを付けた一覧。ログアウトボタン（POST /logout）と「メーカーの方はこちら」（/sellers/apply）導線もここに置く
2. **`/me/edit`**：投稿者として公開されるハンドルとアバターだけを編集する。ハンドル重複はフィールドエラー
3. **`/me/saved`**：保存資材一覧（解除ボタン付き）＋2〜4件選択して「比較する」
4. **`/me/saved/compare`**：選択資材の比較表（名前・メーカー・平均★・レビュー数・対照区あり率・製品タイプ・主なタグ・価格帯）。横スクロールの簡易表でよい（02 §2）
5. 空状態（保存0件・投稿0件）の文言

## 検証（完了条件）

ゲート一式（pipefail で終了コードを正確に）＋実フロー：signup→表示情報編集（アバター含む）→一般ユーザーページ（/users/[id]）に反映→資材保存→/me/saved→2件比較。375px スクリーンショット（/me・edit・compare）。

## 質問すべき条件

- profiles にカラム不足があれば停止して報告（スキーマ変更は別タスク）
