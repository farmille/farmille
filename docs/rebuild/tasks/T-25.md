# T-25 メーカーページ＋公開プロフィール

あなたはモック再現に強いフロントエンドエンジニアです。対象：`/sellers/[id]`・`/users/[id]`。見た目の正はモックの seller / profilePublic 画面（`docs/rebuild/reference/screens/` の各 txt＋モック HTML）。sellerJA は D17 により対象外です。仕様は `docs/rebuild/02-screens.md` §2・§4。

## 制約

- 触ってよいのは `src/app/sellers/[id]/`・`src/app/users/[id]/`（いずれも新規）・`src/server/queries/`（追加のみ）・components/ への追加
- T-21 の共通コンポーネント使用・server 層経由・ハードコード禁止・用語は D8
- データは公開ビュー相当（public_sellers／public_profiles）経由。一般ユーザーはハンドル・アバター・登録日時以外、メーカーは contact_* などの内部情報が**絶対に**レスポンスへ載らないこと

## 実装

1. **`/sellers/[id]`**（メーカー公開ページ）：
   - 組織ヘッダ（ロゴ・名称＋公式マーク・紹介文・公式サイトリンク・主な地域）
   - 統計カード：掲載資材 N 件・参考になった数（**回答数は表示しない**＝Q&A Phase 2）
   - 掲載資材：claim 済み資材の横スクロール＋「すべて見る」相当の全件導線（件数が3超なら）。**0件時は資材セクションの代わりに告知バンド**「このアカウントは記事・回答で情報発信を行っています」→ 文言は Phase 1 に合わせ「記事で情報発信を行っています」
   - 投稿記事一覧（published）
   - 公式回答セクションは**実装しない**（Phase 2）
   - approved 以外のメーカーは notFound
2. **`/users/[id]`**（一般ユーザーページ）：
   - ヘッダー：アバター・ハンドルだけを表示する。内部属性の立場を含め、プロフィール属性は公開しない
   - 統計：レビュー数・参考になった数（回答数は含めない）
   - これまでの投稿：レビュー（→資材詳細のアンカー）＋使用レポート（→ /reports/[id]）の時系列
   - 存在しない id は notFound
3. **リンク結線の徹底**（02 §4-10）：ReviewCard・ReportCard の投稿者名／アバターから `/users/[id]` へ飛べるよう、T-21 コンポーネントに author リンク props が無ければ**拡張してよい**（後方互換を保つ optional prop で）
4. generateMetadata（両ページ）

## 検証（完了条件）

ゲート一式＋ローカルスタック＋シード（T-24 が seed.sql を作っていれば再利用・無ければ自作してよい）で 375px 実表示：資材ありメーカー／0件メーカーの分岐・一般ユーザーページにハンドルとアバター以外の属性が表示されないこと。スクリーンショット添付。

## 質問すべき条件

- public ビューに不足カラムがあれば server 側で実テーブルへ逃げず、停止して報告

実装ファイル一覧／検証結果（一般ユーザー属性の非保持確認を含む）／T-21 コンポーネント拡張の一覧／モックとの意図的差分。
