# T-25 出品者ページ（統合版）＋公開プロフィール

あなたはモック再現に強いフロントエンドエンジニアです。対象：`/sellers/[id]`・`/users/[id]`。見た目の正はモックの seller / sellerJA / profilePublic 画面（`docs/rebuild/reference/screens/` の各 txt＋モック HTML）。仕様は `docs/rebuild/02-screens.md` §2・§4。

## 制約

- 触ってよいのは `frontend/src/app/sellers/[id]/`・`frontend/src/app/users/[id]/`（いずれも新規）・`frontend/src/server/queries/`（追加のみ）・components/ への追加
- T-21 の共通コンポーネント使用・server 層経由・ハードコード禁止・用語は D8
- データは公開ビュー相当（public_sellers／public_profiles）経由。contact_*・standpoint・非公開 prefecture が**絶対に**レスポンスへ載らないこと

## 実装

1. **`/sellers/[id]`**（seller と sellerJA を**1画面に統合**・02 §4-6）：
   - 組織ヘッダ（ロゴ・名称＋公式マーク・種別ラベル・紹介文・公式サイトリンク・主な地域）
   - 統計カード：掲載資材 N 件・参考になった数（**回答数は表示しない**＝Q&A Phase 2）
   - 掲載資材：claim 済み資材の横スクロール＋「すべて見る」相当の全件導線（件数が3超なら）。**0件時は資材セクションの代わりに告知バンド**「このアカウントは記事・回答で情報発信を行っています」→ 文言は Phase 1 に合わせ「記事で情報発信を行っています」
   - 投稿記事一覧（published）
   - 公式回答セクションは**実装しない**（Phase 2）
   - approved 以外の seller は notFound
2. **`/users/[id]`**（公開プロフィール）：
   - プロフィールカード：アバター・ハンドル・地域（公開時のみ）・主な作目チップ・栽培形態チップ・**所属バッジ（D5・任意項目）**・一言・外部リンク（website/sns・あれば）
   - 統計：レビュー数・参考になった数（回答数は含めない）
   - これまでの投稿：レビュー（→資材詳細のアンカー）＋使用レポート（→ /reports/[id]）の時系列
   - 存在しない id は notFound
3. **リンク結線の徹底**（02 §4-10）：ReviewCard・ReportCard の投稿者名／アバターから `/users/[id]` へ飛べるよう、T-21 コンポーネントに author リンク props が無ければ**拡張してよい**（後方互換を保つ optional prop で）
4. generateMetadata（両ページ）

## 検証（完了条件）

ゲート一式＋ローカルスタック＋シード（T-24 が seed.sql を作っていれば再利用・無ければ自作してよい）で 375px 実表示：資材あり seller／0件 seller の分岐・非公開 prefecture のユーザーで地域非表示・standpoint がページソースに現れないこと（`curl | grep standpoint` で0件）。スクリーンショット添付。
