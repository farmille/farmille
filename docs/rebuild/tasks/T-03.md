# T-03 デザイントークン実装（ライトのみ）＋スタイルガイドページ

あなたはデザインシステムの実装に長けたフロントエンドエンジニアです。モックの見た目を Panda CSS のトークン・レシピとして正確に写し取る。

## 制約

- 触ってよいのは `panda.config.ts`・`src/app/dev/tokens/`（新規）・`src/app/globals.css`（存在すれば）のみ。他のページ・コンポーネントは触らない
- **ダークモード禁止**：`_dark`・`prefers-color-scheme`・テーマ切替を一切書かない（docs/rebuild/00 D12）
- 生値の直書きはトークン定義（panda.config.ts）の中だけ。ページ側は必ずトークン参照
- 値の正は `docs/rebuild/02-screens.md` §5 の表。元データはモック `docs/rebuild/reference/mockup-sp-19screens.html` の `:root`（ライト側のみ。`data-theme="dark"` ブロックは無視）

## 手順

1. `panda.config.ts` の `theme.tokens` を定義：colors（green 階調・green.deep/soft/soft2・blue・star・amber/amber.soft・bg/panel/card・ink 3段・line 2段）・shadows（shadow・shadow.lift）・radii（pill/card/button/input）・fontSizes（8段。02 §5 のタイポスケールに `xs`〜`3xl` 相当の名前を付ける）・spacing は Panda 既定＋必要な補完のみ
2. `theme.semanticTokens` を定義：`brand.primary`／`brand.primaryDeep`／`brand.soft`／`text.default`／`text.muted`／`text.subtle`／`surface.page`／`surface.panel`／`surface.card`／`border.default`／`border.strong`／`accent.official`（blue）／`accent.star`／`accent.warn`
3. フォント：ルートレイアウトで読み込む Gen Interface JP を `fonts.sans` トークンに接続
4. `/dev/tokens` ページ（Server Component）：色見本（トークン名＋実値）・タイポスケール・角丸・影・チップ/カード/ボタンの素朴なサンプルを一覧表示。**本番ビルドから除外**（`notFound()` を production で返す等、Next 16 の流儀で）
5. 検証・コミット

## 検証（完了条件）

```bash
pnpm lint && pnpm format:check && pnpm exec tsc --noEmit && pnpm build
pnpm dev  # http://localhost:3000/dev/tokens を開き、色・タイポ・角丸がモックの見た目と一致することを目視
```

スクリーンショット（/dev/tokens 全体）を撮って報告に添付すること。

## 質問すべき条件

- 02 §5 とモック HTML の値が食い違う場合は 02 §5 を正とし、相違点を報告に列挙

## 最終報告の形式

定義したトークンの一覧（カテゴリごと件数）／検証結果／スクリーンショットのパス／相違点一覧。
