# T-23 資材詳細＋レビュー全件一覧＋資材の関連記事

あなたは情報密度の高い詳細ページの実装に強いエンジニアです。対象：`/materials/[id]`・`/materials/[id]/reviews`・`/materials/[id]/articles`。見た目の正はモックの material / materialArticles 画面（`docs/rebuild/reference/screens/material.txt`・`materialArticles.txt`＋モック HTML）。仕様は `docs/rebuild/02-screens.md` §2・§4。

## 制約

- 触ってよいのは `frontend/src/app/materials/`（新規）・`frontend/src/server/queries/`（追加・拡張。既存シグネチャ変更禁止）・必要なら `frontend/src/components/` への追加
- T-21 の共通コンポーネントを使う。データは server 層経由・ハードコード禁止
- **Q&A 区画は実装しない**（Phase 2。監査 §4-5）
- 資材詳細は「倉庫」：ページ内埋め込み＋スクロールで完結（02 §1）

## 実装

1. **`/materials/[id]`**（上から順・モック material 画面の構成）:
   - hero：画像・資材名・メーカー名（公式マーク＝claim 済みのみ）・平均★・レビュー件数。メーカー名は claim 済みなら `/sellers/[id]` へリンク、未 claim はテキスト
   - 外部リンク（製造元公式ページ・カタログ PDF。値が無ければ非表示）＋掲載情報の免責文（モックの文言どおり）
   - 資材詳細テーブル（一般用途・製品タイプ・主成分・作用機序・効果分類・対象作目・販売状況・製造元）。「メーカー確認済み」バッジは claim 済みのみ
   - エビデンス（SDS・試験結果・論文。material_evidences から。無ければセクション非表示）
   - 使用レポート抜粋（published 3件＋「すべて見る」→ /articles?material=…でなく `/materials/[id]/articles`）
   - レビューサマリー（平均・件数・星分布バー・**対照区あり率の1行**＝確からしさ指標）＋レビュー3件＋「レビューをすべて見る（N件）」→ `/materials/[id]/reviews`
   - 保存トグル（検討リスト）：ログイン済みは saved_materials へ追加/削除（Server Action・useOptimistic 可）、未ログインはログインへ誘導
   - FabBar（「使用レポートを書く」→ `/materials/[id]/report/new`・「レビューを書く」→ `/materials/[id]/review/new`。未実装ルートで404可）
   - 存在しない id は notFound()
2. **`/materials/[id]/reviews`**：全件一覧＋並び替え（新着順／参考になった順／星の高い順）＋ページネーション。`#review-<id>` アンカー対応
3. **`/materials/[id]/articles`**：この資材に紐づく記事＋使用レポートの一覧（タイトルは資材名を動的に）
4. generateMetadata（資材名・description・OGP）

## 検証（完了条件）

ゲート一式（lint/format:check/tsc/vitest/build）＋ローカルスタック（除外オプション付き起動・シード15件・終了時 stop --no-backup）で 375px 実画面確認：15件のうち2資材以上で詳細表示・保存トグル動作（signup してから）・レビュー0件時の空状態・notFound。スクリーンショット添付。
