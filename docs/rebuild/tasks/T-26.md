# T-26 SEO 基盤（metadata・OGP・sitemap・構造化データ）

あなたは Next.js の SEO 実装に詳しいエンジニアです。前提：D6（全公開・SEO 優先）。対象は公開ページ全部（/・/search・/materials/[id]（＋reviews・articles）・/articles・/articles/[id]・/reports/[id]・/sellers/[id]・/users/[id]）。

## 制約

- 触ってよいのは `src/app/` 配下の metadata 関連（layout.tsx の metadata・各ページの generateMetadata の追補）・`src/app/sitemap.ts`・`src/app/robots.ts`・`src/app/opengraph-image.tsx`（任意）・`src/lib/seo.ts`（新規ヘルパ）・`src/server/queries/`（sitemap 用の一覧関数追加のみ）
- 既存ページの表示・ロジックは変更しない（metadata の追加・整理のみ）。既存 generateMetadata がある場合は壊さず拡充
- URL は `NEXT_PUBLIC_SITE_URL` から組み立て（env.ts 経由・フォールバック禁止）

## 実装

1. ルート layout：title template（`%s | Farmille`）・既定 description・OGP/Twitter カード既定値・`lang="ja"` 確認
2. 各公開ページの generateMetadata を点検・補完（一覧系は静的文言・詳細系はデータ由来。noindex：/dev/*・認証系・/me 系・/post・/dashboard・/admin）
3. `src/app/sitemap.ts`：静的ルート＋ materials・articles・reports・sellers・users の published/approved 一覧（server 層の軽量クエリを追加。id と updated_at のみ）
4. `src/app/robots.ts`：全許可＋ sitemap 参照＋ /admin・/dashboard・/me・/api の Disallow
5. 構造化データ（JSON-LD）：資材詳細に Product＋AggregateRating（レビュー0件時は aggregateRating を出さない）・レビュー全件ページに Review リスト（上位のみ）・記事/レポート詳細に Article。`lib/seo.ts` に生成関数を置き、`<script type="application/ld+json">` で埋め込み
6. OGP 画像：既定1枚（ブランドグリーンのシンプルな生成画像 or 静的）。ページ個別 OGP 画像は作らない（M5 で検討）

## 検証（完了条件）

ゲート一式＋ローカルで `curl` により：/sitemap.xml が有効 XML で主要 URL を含む・/robots.txt・資材詳細の HTML に JSON-LD が含まれ [Schema.org validator 相当の構文]（`node -e` で JSON.parse）で妥当・noindex ページに robots meta が付く。結果を貼付。

## 質問すべき条件

- 構造化データに必要な値がスキーマに無い場合は省略し、報告に列挙（スキーマ変更は提案のみ）

## 最終報告の形式

実装ファイル一覧／検証結果（curl 出力の要点）／noindex 対象一覧／省略した構造化データ項目。
