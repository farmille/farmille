# T-02 アプリ再初期化（Panda CSS／oxlint／oxfmt／fail-fast env）

あなたは Next.js 16 と最新フロントエンドツールチェーンに精通したエンジニアです。作業ディレクトリはリポジトリルートとし、`src/` とルート直下のアプリ設定ファイルだけを変更します。`docs/`・`tools/`・`supabase/` には一切触らないこと。

## 制約

- Next.js は 16.2.x のまま（アップグレード・ダウングレードしない）。**Next 16 は学習データと規約が異なる**。迷ったら `node_modules/next/dist/docs/` の該当ガイドを読むこと（`AGENTS.md` 参照）
- silent fallback 禁止：環境変数の `?? "既定値"` を書かない
- デザイントークンの本実装は別タスク（T-03）。ここでは Panda が動く最小構成＋ブランドグリーンのプレースホルダトークンまで
- ダークモード関連の設定・条件は一切作らない（ライトのみ。docs/rebuild/00 D12）
- 旧 src/ のコードは指定の3ファイル以外持ち込まない

## 背景

アプリ全面刷新。Tailwind を廃止して Panda CSS へ、lint/format を oxlint＋oxfmt 主体へ移行する（設計: docs/rebuild/03-architecture.md §3・§4・§8）。この後のタスクは全部この足場の上に積まれる。

## 手順

1. **一掃**：`src/` の旧実装全削除・`public/` の svg 5点削除・Tailwind 関連（tailwindcss・@tailwindcss/postcss・postcss.config.mjs の tailwind 参照・globals.css の tailwind 記法）除去
2. **依存整理**（docs/rebuild/05 §2）：削除＝tailwind-merge・clsx・@radix-ui/react-dialog・@radix-ui/react-label・@radix-ui/react-popover・@radix-ui/react-slot・class-variance-authority・cmdk・@dnd-kit/*。維持＝next・react・@supabase/ssr・@supabase/supabase-js・@sentry/nextjs・@next/third-parties・lucide-react・unified/remark*/rehype* 系。**dev 依存の脆弱性解消**：vitest を ^3.2.6 以上・happy-dom を ^20.8.9 以上へ更新し、`pnpm audit --audit-level=high` で critical/high 0 件にする（`ws` が残る場合は pnpm overrides で `"ws": ">=8.21.0"`）
3. **Panda CSS**：`@pandacss/dev`（1.11 系）＋ postcss。`panda init --postcss` 相当の構成。`package.json` の `prepare` に `panda codegen`。`styled-system/` は gitignore。`tsconfig.json` include に styled-system。`panda.config.ts` は `theme.tokens.colors.green.{50,500,700,900}`（#E8F5E9／#4CAF50／#2E7D32／#1B5E20）と `radii.card=14px` だけ置く（トークン全量は T-03）
4. **フォント**：`next/font` の `Noto_Sans_JP` を CSS 変数（`--font-noto-sans-jp`）で読み込み、`src/app/layout.tsx` の `<html>` に className を付与
5. **lint/format**（docs/rebuild/03 §4）：
   - `.oxlintrc.json`：plugins = eslint, react, unicorn, typescript, nextjs, oxc。type-aware 有効。ignorePatterns に .next/ styled-system/ node_modules/
   - `eslint.config.mjs`：eslint-config-next（core-web-vitals＋typescript）＋ 最後に `eslint-plugin-oxlint` の flat/recommended
   - oxfmt：バージョンを devDependencies に **exact で pin**。設定は最小
   - scripts：`lint`=`oxlint && eslint .`／`format`=`oxfmt`／`format:check`=`oxfmt --check`（oxfmt の実 CLI 仕様に合わせて調整可）／`check`=`pnpm lint && pnpm exec tsc --noEmit && pnpm exec vitest run`
6. **src 構造**（docs/rebuild/03 §2・§7）：
   - `src/env.ts`：必須環境変数の検証。クライアント参照用（NEXT_PUBLIC_SUPABASE_URL・NEXT_PUBLIC_SUPABASE_PUBLISHABLE_KEY・NEXT_PUBLIC_SITE_URL）とサーバー専用（SUPABASE_SECRET_KEY）を分離し、未設定なら**その値を初めて使う時点で明確なエラーを throw**（ビルドは env なしでも通ること。Vercel preview を壊さないため遅延検証にする）
   - `src/app/`：layout.tsx（フォント・メタデータ・lang="ja"）、page.tsx（仮ホーム：Panda の css() でブランドグリーンの見出しを表示する最小ページ）、error.tsx・not-found.tsx（日本語の簡素な文面）
   - `src/server/`：`README.md`（この層の規約1段落：service_role はここのみ・UI から supabase.from 禁止）だけ置く（実装は後続タスク）
   - `src/lib/`：旧コードから3ファイルを移植 — `auth/safe-next.ts`＋`auth/safe-next.test.ts`・`supabase/paths.ts`・`markdown/render.ts`（import 先の無い依存は削除調整可）。移植元はコミット `21c200b` の当時のパス配下（`git show 21c200b:frontend/src/lib/auth/safe-next.ts` 等で取得）
   - `src/components/`：空＋.gitkeep
7. **その他**：`.env.example` を新変数集合（docs/rebuild/03 §6）に更新。`README.md` を実内容（セットアップ・スクリプト・検証コマンド）で書き換え。`vercel.json` から cron 定義を削除（ファイルごと不要なら削除）。`next.config.ts` は Sentry 設定を維持しつつ Tailwind 依存があれば除去
8. **検証**して**コミット**（意味単位で分割可）

## 検証（完了条件・すべて成功させること）

```bash
pnpm install
pnpm lint
pnpm format:check
pnpm exec tsc --noEmit
pnpm exec vitest run          # safe-next.test が通ること
pnpm build                    # 環境変数なしで成功すること
pnpm audit --audit-level=high # critical/high 0 件
```

## 質問すべき条件

- oxfmt／oxlint の CLI 仕様が想定と異なり scripts 構成を変えたい場合は、変更してよいが最終報告に明記する
- Next 16 の規約でドキュメントを読んでも判断できない場合は、止めて報告する

## 最終報告の形式

変更点の要約／各検証コマンドの結果（成功・失敗・skip を区別）／pin したバージョン一覧／判断に迷って変更した点。
