## 画面ごとの目立つ差分メモ（事実のみ）

1. **ホーム**：構成（検索ボックス・タグ候補・注目のBS資材・新着使用レポート・新着レビュー・登録CTA・下部ナビ）は一致。「アクティビオ検証」の資材カード画像がプレースホルダー表示（`material_images` に画像レコードが無いデータ起因、実装の欠陥ではない）。
2. **資材検索**：タグ選択チップ・条件パネル（よく探されている条件／今の時期におすすめ）・絞り込み条件表示・並び替えセレクト・結果件数の構成が一致。実装は「資材タイプ：バイオスティミュラント」を選択（該当9件）、モックは「悩み：高温対策」を選択（該当2件）。選んだタグが異なるだけで、選択・解除・絞り込みロジック自体の対応は確認できた。
3. **資材詳細**：資材詳細テーブル・SDS/論文データ・使用結果レポート横スクロール・レビューサマリー（星分布）・対照区あり率・レビューの構成が一致。相違：(a) 実装には「ログインして検討リストに保存」ボタンがあるがモックには無い（02-screens.md 監査結論#4で追加が正）。(b) モックにあるQ&A区画（6件・回答例）は実装には無い（02-screens.mdの仕様どおりQ&AはPhase 2まで非表示）。(c) 資材画像がプレースホルダー（ホームと同じデータ起因）。(d) 見出し語が「レビュー」（実装）/「口コミ」（モック）で不一致（D8の用語統一方針により実装側が正）。
4. **レビュー全件一覧**：モック対応なし（新規画面）。並び替えセレクトと2件のレビューカードを表示。総合評価要約カード（4.5・レビュー2件）を上部に表示。
5. **使用レポート閲覧**：対象資材カード・使用目的タグ・環境/使用方法/観察結果/マイナス点/収穫調査（グラフ）/まとめの章立てが一致。相違：モックには「散布の様子（動画 0:42）」の動画枠があるが実装には無い（この使用レポートのメディアに動画が含まれていないデータ起因）。
6. **記事一覧**：検索ボックス・フィルタピル・カード一覧の構成が一致。相違：フィルタピルの3番目のラベルが実装は「記事」、モックは「その他の記事」。
7. **記事詳細**：タイトル・著者（メーカー）・本文・紐づけ資材カードの構成が一致。ヒーロー画像は実装がシードデータの `hero_image_url`（placehold.co の文字入りプレースホルダー画像）をそのまま表示、モックは緑背景にアイコンのみのダミー矩形で見た目が異なる（いずれも本番の実画像ではない）。
8. **メーカーページ**：メーカー情報・掲載製品・投稿記事の構成が一致。相違：モックには「回答数」の統計カードと「公式回答」区画があるが実装には無い（02-screens.md 仕様どおりQ&AはPhase 2まで非表示）。
9. **一般ユーザーページ**：D16 によりアバター・ハンドル・統計（レビュー数／参考になった数）・投稿一覧だけを表示する。地域・栽培形態・自己紹介・所属はモックから意図的に削除した。
10. **マイページ**：表示情報カード・表示情報編集導線・統計・自分の投稿・検討リスト・参考になった・メーカー申請導線で構成する。統計カードのラベルは「レビュー」に統一する。
11. **資材比較**：モック対応なし（新規画面）。2資材（アクティビオ検証／Actibio X EVO53）を列で比較。比較テーブル最終列（主なタグ）が画面右端で折り返し表示となり、スクリーンショット上は列の右側が確認しづらい（横スクロールの有無は本画像だけでは判断不可）。

13. **一般登録**：ハンドルネーム・メールアドレス・パスワード・アイコン案内・登録ボタンで構成する。D16 により都道府県・公開トグル・立場は削除した。

15. **レビュー投稿**：作目ピッカー・総合評価（星タップ）・本文・写真・購入場所・対照区の有無・農薬表現同意チェックの構成が一致。モックは入力済みのサンプル状態（星4・本文・写真2枚）で表示されるのに対し、実装は未投稿ユーザーの空フォーム状態（プロトタイプと実データの違いであり、フォーム構造自体は一致）。
16. **使用レポート投稿（上部）**：対象資材カード・使用作物ピッカー（入力欄＋作目候補チップ）の構成が一致。資材画像は実装側がプレースホルダー（対象資材 Actibio X EVO53 も画像未登録のデータ起因）。

## 撮影方法に関する注記（実装差ではない）

- モックはSPAの電話フレーム内スクロール（`.screen{overflow-y:auto}`・`body.app-mode{overflow:hidden}`）をCSS上書きで解除し、開発用のチップ切替バーを非表示にした上でフルページ撮影した。これにより資材詳細・使用レポートのFABバー（使用結果を入力／口コミを書く）はページ最下部付近に静的表示される（実機では画面下部に固定表示）。
- Next.js の `loading.tsx`（Suspense フォールバック）は初回 `load` イベント後に非同期で実データへ差し替わるため、撮影スクリプトは「読み込んでいます」表示が消えるのを待ってから撮影した。
