# 企業向け申請の受付

## 対象

企業が資材掲載、資材オーナー権限の取得・移行、終売・廃盤表示、非表示を申請する。申請内容、証拠資料、提出時の同意を保存し、受付メールと印刷可能な受付票を提供する。運営は2要素認証後に一覧・詳細・資料を閲覧する。

原稿は[申請フォームA〜Dと運用方針](https://docs.google.com/document/d/1DK40bty1sTmjXzhRXVDSFPEyXV0DTxbgKHz_fa0xO7k/edit)を参照する。委託・委託解除フォームは対象に含めない。

| 申請 | 申請者 | 内容 |
| --- | --- | --- |
| A | 承認済みメーカー | 新規資材の掲載、掲載済み資材のオーナー権限取得 |
| B | 現資材オーナー企業 | 移行先企業へオーナー権限を引き渡す |
| C | 承認済みメーカー | 事業承継などを理由にオーナー権限を引き継ぐ |
| D | 確認済みメールを持つ関係会社 | 終売・廃盤表示、資材ページの非表示 |

審査、当事者との協議、7日・14日の期限管理、権限付与・移行、掲載状態の変更は運営の既存業務として行う。受付処理では資材、編集権、口コミ、公開状態を変更しない。自動PDF生成、電子署名、電子契約は提供しない。

## 入力と保存

4フォームとも複数資材を受け付ける。会社・担当者・署名・申請日の情報と、フォームごとの全確認事項を保存する。法人番号はA〜Cで13桁必須とする。A〜Cの申請者はログイン中のメーカーに結び付け、入力されたIDだけでは本人と判定しない。

Aは資材ごとに新規掲載と既存資材の権限取得を区別する。AとDの関係区分は製造元・販売元・輸入元から複数選択できる。Bは移行先会社と担当者の情報を保存する。Cは現オーナー名、移行経緯、任意の同意資料と承継資料を保存する。Dは資材ごとの申請理由と、その理由を他の関係会社へ開示してよいかを保存する。

資料はJPG・PNG・PDF、1ファイル10MBまで、各添付欄で5ファイルまでとする。パッケージや関与の証拠は資料URLでも指定できる。Cの移行経緯を確認する2種類の資料は任意とする。機密情報をマスキングできる案内を表示する。

提出時の会社名、資材名、回答、同意文面を受付記録に保持する。後から会社プロフィールや同意文面が変わっても、過去の受付票は変えない。受付済み申請を上書き編集したり自動削除したりしない。訂正が必要な場合は受付番号を添えて運営に連絡する。

## メール確認と控え

A〜Cはメーカーダッシュボードの「各種お手続き」から開く。Dは法人名・担当者名・法人メールの簡易受付後、メール内の確認リンクから入力する。メール確認は法人としての申請権限を証明するものではなく、連絡先が利用可能であることを確認する。

受付メールはA〜Cではメーカーに登録された連絡先、Dでは確認済みメールに送る。フォームに入力した移行先企業や現オーナーの担当者へ受付時の通知は送らない。控えの送信先を画面に表示する。

受付メールは受付番号と回答を含む。添付資料のファイル本体はメールに添付せず、閲覧権限のある受付票から確認する。印刷用の受付票ではナビゲーションと操作ボタンを除き、回答と同意内容を印刷する。メール送信が失敗しても受付記録を保持し、未送信であることと再送手段を示す。

## 非公開情報

担当者情報と添付は公開ページへ出さない。メーカーは自社の申請だけを閲覧できる。Dの受付票はメール確認による閲覧権限を必要とする。運営の閲覧は2要素認証を必須とする。受付番号だけで申請内容を取得できないようにする。

## 検証

4フォームの入力、複数資材、資料不足、添付形式と容量、同意不足、二重送信、メール失敗時の記録保持、別会社・未確認・期限切れからのアクセス拒否を確認する。375pxの実画面で送信から受付票と運営閲覧まで操作する。

## 保存と資料

申請・資材行・種類別回答・同意は提出後に変更しない。入力開始時のintentに提出を一意化し、同じ回答の再送は同じ受付番号を返す。異なる回答を同じintentへ送ると拒否する。情報取扱い本文も同意文とともに提出時点で固定する。

添付は非公開Storageへ直接送信し、サーバーが実サイズ・MIME・先頭バイトを検査する。検査したバイト列を専用パスへ保存してから申請に結びつける。各欄5件、1件10MiBまで。提出済み資料の追加・更新・削除をDBでも拒否する。期限切れの未提出資料はフォーム利用時に少量ずつ削除する。

Dの確認リンクは30分有効で、明示的な確認操作後に24時間のHttpOnlyセッションを発行する。確認ページは外部解析を読み込まない。期限切れの受付票は、受付番号と申請時メールアドレスへの再確認で開く。メールアドレスの確認自体は法人の申請権限を証明しない。

控えの送信先はA〜Cがメーカーアカウントの登録連絡先、Dが確認済みメールアドレス。入力した移行先・旧オーナーへの自動送信は行わない。メール送信に失敗しても受付を保持し、申請者と運営が再送できる。SMTP受理とDB記録の間で障害が起きる場合、控えメールが重複する可能性はあるが、受付番号は増えない。

Dの未提出フォームを途中で閉じた場合、入力内容の自動復元は行わない。「入力と添付を破棄して最初から入力」で確認済みメールを維持したまま再開できる。破棄した提出単位は直ちに操作できなくなり、未提出資料の削除対象となる。受付済みの申請はこの操作では変更しない。

## 公開利用ガイド

`/sellers` は企業会員登録から資材掲載までの5段階、必要資料、申請者の条件、既存会員の手続き、FAQを案内する。掲載・権限取得は `/dashboard/applications/new/registration`、引き渡しは `transfer_out`、引き継ぎは `transfer_in`、終売・非表示は `/company-requests/removal` へ進む。資材編集、メーカープロフィール、受付票一覧は既存ダッシュボードを使用する。担当者・連絡先変更は `contact@farmille.com` で受け付ける。登録導線はマイページからの `from=me` を保持する。
