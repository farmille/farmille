# 企業向け申請の受付

## 対象

企業が資材掲載、資材オーナー権限の取得・移行を申請する。申請内容、証拠資料、提出時の同意を保存し、受付メールと印刷可能な受付票を提供する。運営は2要素認証後に一覧・詳細・資料を閲覧する。

原稿は[申請フォームA〜Dと運用方針](https://docs.google.com/document/d/1DK40bty1sTmjXzhRXVDSFPEyXV0DTxbgKHz_fa0xO7k/edit)を参照する（Dは受付を終了した）。委託・委託解除フォームは対象に含めない。

| 申請 | 申請者 | 内容 |
| --- | --- | --- |
| A | 承認済みメーカー | 新規資材の掲載、掲載済み資材のオーナー権限取得 |
| B | 現資材オーナー企業 | 移行先企業へオーナー権限を引き渡す |
| C | 承認済みメーカー | 事業承継などを理由にオーナー権限を引き継ぐ |

終売・廃盤表示と資材ページの非表示の依頼は、申請フォームを設けず `contact@farmille.com` で受け付ける。公開中の資材ページは、編集権を持つメーカーがダッシュボードから非公開にもできる（[メーカーによる資材ページ編集](manufacturer-editor-SPEC.md)）。旧フォームDは提供しない。受付済みのDの受付票は、後述の再確認で引き続き閲覧できる。

審査、当事者との協議、通知から14日の異議期限の管理、権限付与・移行、掲載状態の変更は運営の既存業務として行う。受付処理では資材、編集権、口コミ、公開状態を変更しない。自動PDF生成、電子署名、電子契約は提供しない。

## 入力と保存

A〜Cとも複数資材を受け付ける。会社・担当者・署名・申請日の情報と、フォームごとの全確認事項を保存する。法人番号はA〜Cで13桁必須とする。A〜Cの申請者はログイン中のメーカーに結び付け、入力されたIDだけでは本人と判定しない。

Aは資材ごとに新規掲載と既存資材の権限取得を区別する。Aの関係区分は製造元・販売元・輸入元から複数選択できる。Bは移行先会社と担当者の情報を保存する。Cは現オーナー名、移行経緯、任意の同意資料と承継資料を保存する。

資料はJPG・PNG・PDF、1ファイル10MBまで、各添付欄で5ファイルまでとする。パッケージや関与の証拠は資料URLでも指定できる。Cの移行経緯を確認する2種類の資料は任意とする。機密情報をマスキングできる案内を表示する。

提出時の会社名、資材名、回答、同意文面を受付記録に保持する。後から会社プロフィールや同意文面が変わっても、過去の受付票は変えない。受付済み申請を上書き編集したり自動削除したりしない。訂正が必要な場合は受付番号を添えて運営に連絡する。

## メール確認と控え

A〜Cはメーカーダッシュボードの「各種お手続き」から開く。

受付メールはメーカーに登録された連絡先に送る。フォームに入力した移行先企業や現オーナーの担当者へ受付時の通知は送らない。控えの送信先を画面に表示する。

受付メールは受付番号と回答を含む。添付資料のファイル本体はメールに添付せず、閲覧権限のある受付票から確認する。印刷用の受付票ではナビゲーションと操作ボタンを除き、回答と同意内容を印刷する。メール送信が失敗しても受付記録を保持し、未送信であることと再送手段を示す。

## 非公開情報

担当者情報と添付は公開ページへ出さない。メーカーは自社の申請だけを閲覧できる。運営の閲覧は2要素認証を必須とする。受付番号だけで申請内容を取得できないようにする。

## 検証

A〜Cの入力、複数資材、資料不足、添付形式と容量、同意不足、二重送信、メール失敗時の記録保持、別会社・未確認・期限切れからのアクセス拒否を確認する。375pxの実画面で送信から受付票と運営閲覧まで操作する。

## 保存と資料

申請・資材行・種類別回答・同意は提出後に変更しない。入力開始時のintentに提出を一意化し、同じ回答の再送は同じ受付番号を返す。異なる回答を同じintentへ送ると拒否する。情報取扱い本文も同意文とともに提出時点で固定する。

添付は非公開Storageへ直接送信し、サーバーが実サイズ・MIME・先頭バイトを検査する。検査したバイト列を専用パスへ保存してから申請に結びつける。提出済み資料の追加・更新・削除をDBでも拒否する。期限切れの未提出資料はフォーム利用時に少量ずつ削除する。

受付済みのDの受付票は、受付番号と申請時メールアドレスへの再確認で開く。確認リンクは30分有効で、明示的な確認操作（`/company-requests/receipts/confirm`）後に24時間のHttpOnlyセッションを発行する。確認ページは外部解析を読み込まない。メールアドレスの確認自体は法人の申請権限を証明しない。

SMTP受理とDB記録の間で障害が起きる場合、控えメールが重複する可能性はあるが、受付番号は増えない。

## 公開利用ガイドと受付メール

`/sellers` は写真バナー、企業会員登録から資材掲載までの5段階、準備資料、申請者の条件、初回手続きと登録済み企業の手続き、資材オーナー権限、FAQを案内する。FAQのリンクは同ページの該当手続きへ進む。IDの要否はログイン状態に関係なく表示する。掲載・権限取得は `/dashboard/applications/new/registration`、引き渡しは `transfer_out`、引き継ぎは `transfer_in` へ進む。終売・非表示は `contact@farmille.com` で受け付けると案内し、フォームへは誘導しない。資材編集、メーカープロフィール、受付票一覧は既存ダッシュボードを使用する。法人名・担当者の変更は、メーカープロフィールの編集画面で運営への連絡を案内する。登録導線はマイページからの `from=me` を保持する。

A〜Cの受付メールは `contact@farmille.com` から送信する。法人名と担当者名を宛名に置き、運営の挨拶と代表者の署名を記載する。受付済みのDの受付票を再確認するメールは、新規申請の案内と区別する。
