# 製品DBの取り込み

## 資材の名称

一覧と詳細の見出しには表示製品名を使う。正式名称は資材の詳細に表示する。正式名称、読み、別名も資材検索の対象とする。

## 資材の画像

資材の画像には、容器形状に対応する共通の容器イラストを使用する。実物写真の利用許諾の有無によらず、容器イラストに統一する。

## 作物

正本の階層は大作物群、中作物群、個別作目の3階層とし、小作物群は使用しない。個別作目はFarmilleタグ一覧の表示名と同義語を使用する。ただし、表示名の括弧の中が言い換え・読み・外来名にあたる個別作目（例：ホースラディッシュ（西洋わさび））は、括弧の前を表示名とし、括弧の中を同義語に加える。切花・球根・品種のように区別に要る括弧と、括弧を外すと既存の個別作目と同名になるものは、表示名をそのまま使う。分類への直接記載と個別作目への直接記載は区別し、表示する関連を上位・下位へ推測して増やさない。

## 公開資料

製品DBの「資材ページのリンク」に含まれる資料を公開対象とする。画像ファイルへの直接リンクは公開対象から除く。

製品DBから取り込む公的試験結果とその他の試験結果は、資料名とURLがあれば掲載できる。概要と実施機関が未入力であることを理由に掲載を拒否しない。

取り込んだ資料は、資材の資材オーナー権限を持つメーカーも編集・削除できる。変更は既存の原稿保存、表現確認、公開の手順で反映する。

## 再取り込み

前回の取り込み後に運営またはメーカーが変更した項目と、製品DBの値が食い違う場合は、差分を確認してから反映する。メーカーが削除した資料を再取り込みだけで復活させない。

メーカーの本文、口コミ、保存を取り込みで上書きしない。既存資材の識別子と投稿の参照を維持する。

掲載保留・除外・未判定の製品は公開しない。旧分類は投稿からの参照を残したまま選択肢から外す。同名製品の統合と区別は `tools/catalog/product-map.json` と `tools/catalog/desired.ts` に従う。

## 保存構造

正式名称と読み、容器形状の番号は資材に保持する。別名は資材ごとの集合として保存する。容器形状は0から10の分類マスタを参照し、0の「その他」と未分類の資材には共通のプレースホルダーを表示する。

取り込み資料は原稿版の資料として保存する。取り込み版の作成元は運営とし、メーカーやメーカー資材オーナー権限を作成者として記録しない。取り込みによってメーカー確認済みの属性は付与しない。

前回の出典値のハッシュは資材・項目ごとに保持する。出典が変わっていなければ現在の編集結果を維持する。出典と現在値の両方が前回の出典値から変わっている場合は競合とする。現在値を維持する解決でも、確認した出典値を次回の比較基準とする。初回の比較基準がない項目は、既存値との差分を確認してから反映する。

取り込み履歴と比較基準は一般公開しない。取り込みは単一トランザクションで適用し、計画作成後の変更を検出した場合は全体を中止する。下書き・表現確認中・修正待ちの原稿がある資材では、原稿と競合する取り込みを自動適用しない。
