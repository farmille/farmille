# 実証詳細レポートの閲覧範囲

実証詳細レポートの全文はログインした会員が閲覧できる。一般・メーカー・運営のいずれも対象とし、資材検索・感想口コミ・規約・メーカー記事はログイン不要で閲覧できる。

未ログイン時は、公開済み資材に属する公開済みレポートについて、タイトル・投稿者・作物・目的タグ・先頭画像・使用感の冒頭200文字までを表示する。一覧用の要約は120文字までとする。残りの本文、環境、施用条件、定量データ、比較画像は返さない。

本文の続きは装飾用のぼかしと無料会員登録・ログインへの案内に置き換える。ぼかしに実際の非公開本文は使わない。ログイン後は対象レポートに戻る。

DBの公開一覧RPCは公開用の項目だけを返す。未ログインでは本文の原本テーブルと施用・定量データを直接取得できず、画像の参照情報も先頭画像に限定する。投稿者自身の下書き・運営の編集権限は維持する。
