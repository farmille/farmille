# 07 アカウント別画面遷移図

更新日：2026-08-24

一般ユーザーとメーカー・出品者の登録入口を分離した現行実装の画面遷移図。メーカー・出品者は申請時点ではアカウントを利用できず、運営の審査とログイン情報の発行を経てから出品者ダッシュボードへ進む。

拡大表示用：[PNG](assets/account-flow/account-screen-flow.png)／[SVG](assets/account-flow/account-screen-flow.svg)

## 1. アカウント別の入口

| アカウント | 作成・申請 | ログイン | ログイン後 | 審査 |
|---|---|---|---|---|
| 一般ユーザー | `/signup` → `/signup/general` | `/login` | `/me` など | なし |
| メーカー・出品者 | `/signup` → `/sellers/apply` | `/sellers/login` | `/dashboard` | 運営の承認が必要 |
| 運営 | 運用で発行 | `/login` → `/admin/mfa` | `/admin` | AAL2 が必須 |

## 2. 分岐のルール

- `/signup` では、入力を始める前に個人用と組織用を選ぶ。
- 一般登録の「メーカー関係者」は、個人プロフィールの非公開属性。選択してもメーカー・出品者権限は付かない。
- メーカー・出品者申請ではパスワードを受け付けない。運営が申請内容を確認し、承認時に共有ログインを発行する。
- 申請が却下または凍結された場合は、出品者ログインへ進めない。
- 一般ユーザー、メーカー・出品者、運営でログイン入口とログイン後の画面を分ける。

## 3. スクリーンショットの範囲

登録方法選択、一般登録、一般登録完了、メーカー・出品者申請、申請受付完了、一般ログイン、出品者ログインは、2026-08-23 の本番ビルドを375px幅で撮影した。出品者審査一覧と審査詳細は、内部ステータス値と設計メモを画面から除いた2026-08-24版を1280px幅で再撮影した。その他のホーム、マイページ、出品者ダッシュボードは、各実装タスクで取得した検証画像を使用している。

公開コンテンツ、投稿、資材編集、記事管理を含む全ルートの遷移は [06-diagrams.md](06-diagrams.md) §3 を参照する。
