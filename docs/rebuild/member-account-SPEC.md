# 一般会員の登録情報と退会

一般会員が、登録した非公開の情報を自分で確認・変更し、マイページから退会する。退会後の投稿と個人情報の扱いは、総合利用規約第13条、投稿ガイドライン11、プライバシーポリシー10に従う。

## 入口

- マイページ下部の操作（パスキーを管理・パスワードを変更・ログアウト）の並びに「登録情報を確認・変更」と「退会する」を置く。「退会する」は並びの最後に置く。
- 企業会員と運営のアカウントには出さない。どちらの画面も、一般会員でないアカウントで開いたときは既存の `/account/*` と同じ扱いにする。

## 登録情報の確認・変更（`/account/details`）

- メールアドレスは表示だけとし、変更したいときの問い合わせ先（contact@farmille.com）を添える。
- 本名（姓・名）、電話番号、郵便番号、都道府県、市区町村・番地、建物名・部屋番号を、登録時と同じ入力欄・規則（必須、文字数、全角の変換、郵便番号からの補完、公開・非公開の表示）で変更できる（`general-registration-SPEC.md`）。
- 都道府県は公開プロフィールの都道府県（`profiles.prefecture_code`）を書き換える。ほかの項目は非公開連絡先（`profile_contact_details`）を書き換える。
- 保存できたら「登録情報を保存しました」を出す。

## 退会（`/account/withdraw`）

- 押す前に、退会すると次のようになることを示す。
  - 本名・メールアドレス・電話番号・住所・パスワード・パスキーを削除し、ログインできなくなる。
  - 投稿した実証詳細レポートと感想口コミは削除されず、投稿者名は「退会済みユーザー」と表示される。プロフィールは表示されなくなる。投稿を消したいときは、退会の前に自分で削除する。
  - お気に入りと保存した投稿は削除される。
  - 同じメールアドレスで新しく会員登録できる。以前の投稿は引き継がれない。
  - 退会は取り消せない。
- 今のパスワードを入力して「退会する」を押す。パスワードが違うときは退会しない。
- 退会が済んだらログアウトし、`/account/withdrawn` で退会が完了したことを示す。この画面はログインなしで開ける。退会前のメールアドレスに「【Farmille】退会手続きが完了しました」を送る（文面は `src/lib/account-email.ts`）。

## 退会の処理

- 公開プロフィールを消す。ニックネームは別の会員が使えるように空け、アイコン・自己紹介・所属・栽培作目・ホームページ・SNSを削除する。プロフィールの行は投稿との結び付きのために残し、退会した日時を記録する。
- 非公開連絡先、お気に入り、保存した投稿を削除する。
- Supabase Auth のユーザーは論理削除（soft delete）し、メールアドレス・パスワード・パスキー・セッションを消す。行は残るので、投稿は削除されない。
- 処理は何度実行しても同じ結果になるようにする。途中で失敗したときは、ログインが残っていれば、もう一度「退会する」を押すと最後まで進む。

## 退会済みユーザーの表示

- 投稿カード、投稿の詳細、参考になった・閲覧数などの集計では、投稿者名を「退会済みユーザー」とし、アイコンは既定の画像、立場と都道府県は出さず、プロフィールへのリンクを付けない。
- 退会済みユーザーのプロフィールページ（`/users/[id]`）は「見つかりません」とする。
- 運営の画面では、退会済みであることが分かるように表示する。

## 検証

一般会員で登録情報を変更して保存し、プロフィールと登録情報の画面に反映されること。投稿のある一般会員で退会し、ログインできなくなること、投稿が「退会済みユーザー」で残ること、プロフィールページが見つからないこと、同じメールアドレスとニックネームで新しく登録できることを、ローカルSupabaseとMailpitで、PCと375pxの画面で確認する。
