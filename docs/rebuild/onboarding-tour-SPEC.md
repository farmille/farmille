# 初回ログインの案内（チュートリアル）

新規会員登録をした一般会員が、登録後に初めてログインしたときに、プロフィールの設定・資材の検索・感想口コミの投稿を実際の画面で順に案内する。見本：初回ログインのガイドツアー（Artifact Xi7bn2XYVsh79GqJX2QfLr）。

## 出す条件

- 一般会員登録を完了したアカウントに「案内待ち」の印（Supabase Auth の `app_metadata.onboarding = "pending"`）を付け、印のあるアカウントでログインしたときに案内を出す。どの端末で初めてログインしても出る。
- 案内の進み具合（いまどの段階か）は、案内中のブラウザの `localStorage`（キー `farmille:onboarding`）に、利用者の id と合わせて置く。別の端末でログインし直したとき、また共用のブラウザで別のアカウントがログインしたときは、ようこそから始まる。
- 手元のセッションに印があるときは、サーバーで今の利用者の印を確かめてから案内を出す。別の端末で案内を終えた後に、古いセッションで案内を出し直さない。
- 案内を最後まで進めて「閉じる」を押したとき、または「チュートリアルを終了」を押したときに、アカウントの印とブラウザの進み具合を消し、以後はどの端末でも出さない。
- 企業会員・運営のアカウントでは出さない。

## 流れ

| 段階 | 画面 | 案内 | 次へ進む操作 |
|---|---|---|---|
| ようこそ | ログイン後の画面 | 下からのシート | 「はじめる」 |
| 1 プロフィール | `/me/edit` | 「栽培作目」の欄を示す。下の帯に「保存する」 | 帯か画面の「保存する」で保存し、保存できたら「プロフィールを保存しました」を出す |
| 2 資材の検索 | `/search` | 検索欄を示す | 検索結果などから資材ページ（`/materials/[id]`）を開く |
| 2 資材の検索 | `/materials/[id]` | 下の帯で、画面の下に実証詳細レポートと感想口コミがあることを示し、帯の上に「下へスクロール」（押すと実証詳細レポートの見出しまで送る）を出す | 実証詳細レポートの見出しが画面の上半分に来るまでスクロールする |
| 3 感想口コミ | `/materials/[id]` | 「感想口コミを書く」を示す | 「感想口コミを書く」で投稿画面を開く |
| 終了 | `/materials/[id]/review/new` | 「チュートリアルはこれで完了です」のシート（使用したことのある資材があれば記入するよう案内） | 「閉じる」で「ありがとうございました」を短く出し、ホームに戻って案内を終える |

- 案内の間も画面は普段どおり操作できる。案内を読まずに自分で操作しても、上の「次へ進む操作」をすれば次の段階へ進む。
- 案内の最後のシートは投稿画面で出す。3の段階で「この手順をスキップ」を押したときは、その資材ページで出す。投稿画面の入力と「投稿する」の案内はせず、案内から感想口コミを送信しない。
- どの場面にも「この手順をスキップ」（次の段階へ）と「チュートリアルを終了」（以後出さない）を出す。
- 案内中にほかの画面へ移ったときは、その段階の画面に戻るまで案内を出さない。
- プロフィールの段階は、保存できたとき（マイページへ `?saved=profile` 付きで戻ったとき）だけ次へ進む。保存できずにマイページへ移ったときはプロフィールの段階に戻る。

## 文面

- 見出しは名詞形、説明は主語と述語のそろった「です・ます」の文にする。補足は「（複数選択可）」のように括弧で添える。
- 語りかけ（「〜してみましょう」）、意味のない体言止め、不要な対比は使わない。

## 検証

- 新規登録 → ログイン → 案内の最後まで進み、2回目のログインで出ないこと。別のブラウザで初めてログインしても出ること。
- 案内を読まずに「保存する」や検索結果を押しても、次の段階へ進むこと。
- 投稿画面が開いたら終了のシートが出て、「閉じる」で「ありがとうございました」の後にホームへ戻ること。
- 企業会員でログインしたときに出ないこと。
