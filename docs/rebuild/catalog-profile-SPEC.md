# 資材マスタと公開プロフィール

## 資材の識別

製品DBのライゾー（PRD-000085・PRD-000377）は1資材に統合する。両方の確定済み表示値と出典を保持し、同一の表示値は重複させない。未確定の表示値は公開しない。

カルビタP（PRD-000139・PRD-000140）は、りんご向け・みかん向けを区別した2資材として残し、表示名に用途を添える。

## 作物

正本の階層は大作物群、中作物群、個別作目の3階層とし、小作物群は使用しない。個別作目はFarmilleタグ一覧の表示名と同義語を使用する。分類への直接記載と個別作目への直接記載は区別し、表示する関連を上位・下位へ推測して増やさない。

## プロフィール

[所属](../../CONTEXT.md)は複数の自由入力から利用可能にする。所属候補はJA全青協、4Hクラブ、日本農業法人協会、JA営農指導員、都道府県 農業普及指導員、都道府県 農業研究員、農研機構 研究員、大学 研究員、その他の順で表示し、候補外の自由入力も維持する。登録時には作目・所属を要求せず、登録後に設定を案内する。

市区町村は本人が公開を選んだ場合だけ公開する。初期値は非公開とする。一般ユーザーの新規登録では番地を必須、建物名・部屋番号を任意とする。町名・丁目・番地と建物名・部屋番号は非公開連絡先として保存し、市区町村の公開設定にかかわらず公開しない。既存会員の未登録住所は補完しない。

立場の内部値は維持し、JAは「JAグループ職員（営農指導員など）」、その他は「その他（メーカー関係者、専門家、大学研究員など）」と表示する。

## 同名製品と移行対象

ハーモザイム（PRD-000030・PRD-000104）も1資材に統合し、両方の確定値と出典を保持する。ジャックスパワー554（PRD-000125・PRD-000126）は2資材として維持し、都府県限定品を名称で区別する。

掲載保留・除外・未判定の製品は公開しない。既存資材のIDを維持し、旧分類は投稿からの参照を残したまま選択肢から外す。資材の画像と再取り込みは[製品DBの取り込み](catalog-import-SPEC.md)に従う。原資料の表示値・出典は非公開の正規化テーブルに保持する。

取り込み時は対象項目とメーカーの編集原稿・権利設定を再確認する。投稿・保存・原稿履歴の参照を保持し、参照先の統合に競合がある場合は、解決するまで変更しない。

## 郵便番号と登録案内

郵便番号による都道府県・市区町村・町名の補完には、jposta が同梱する日本郵便の郵便番号データをサーバー上で検索し、郵便番号を外部へ送らない。町名は番地欄に入れる。番地の数字は自動補完しない。「以下に掲載がない場合」と「番地がくる場合」の町名は入れない。複数の市区町村、または複数の町名にまたがる郵便番号は、分かれた部分を手入力する。

登録完了メールは新規プロフィールの作成時に送信待ちとして記録し、メール確認後に本人へ送信する。既存会員へ一斉送信しない。メーカー承認時のログインID・パスワード設定案内は、申請時の連絡先へ送信する。
