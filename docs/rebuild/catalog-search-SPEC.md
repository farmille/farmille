# 資材検索

資材名・正式名称・読み・別名、メーカー名、作物、効果、悩み、栽培条件を検索対象とする。文字列は全角・半角、英字の大文字・小文字、ひらがな・カタカナを区別しない。

悩みタグには複数の同義語と対応する効果分類を登録できる。例えば「水不足」「水分不足」は「耐乾燥性改善」、「暑さ対策」「高温障害」は「耐暑性改善」に対応する。「気候変動」「気象変動」は複数の環境ストレスに関する分類へ対応する広い検索語として扱う。

悩みタグを検索・選択したときは、そのタグを直接持つ資材と、対応する効果分類を持つ資材を合わせて返す。同じ資材は重複させない。資材に保存済みの効果分類やメーカーの説明は変更しない。検索での一致は、個々の栽培条件における効果の保証を意味しない。

同じ分類の選択肢はOR、異なる分類の条件はANDで組み合わせる。キーワードを加えた場合は、選択済みの条件も満たす資材に絞る。公開中の資材だけを返す。

同義語と効果分類の対応は運営が管理する。初期データは25の効果分類を対象とし、migrationで登録する。既存タグの識別子・名称・並び順・資材への直接の関連を維持する。資材または効果分類との関連があるタグを使用中として扱い、運営のタグ管理から削除できないようにする。

新聞記事は検索語を整備するための出典として利用する。記事本文で確認した言葉と、そこから補った表現を区別し、出典と対応理由を[検索語の調査記録](../research/catalog-search-vocabulary.md)に残す。原因が複数ある症状や特定資材だけの作用を、一般の効果分類へ一律に対応させない。

「糖度低下」は糖度を改善したい悩みとして「糖度増加」に対応する。複合語を追加する際は、短い検索語の一致先も確認する。「凍霜害」は保留し、「霜」の検索を「耐寒性改善」へ広げない。

口コミ・レポート本文、新聞記事、未公開のメーカー原稿はこの検索の対象に含めない。
