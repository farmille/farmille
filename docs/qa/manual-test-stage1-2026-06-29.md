対象仕様：`docs/specs/review-images-and-admin-review-actions.md`（stage1 軽微修正）

このチェックリストは「実際に人が手で触って確認する」ためのものです。各シナリオは

仕様 §4 の受け入れ基準 **A1〜A4 / B1〜B4** を漏れなくテスト項目化しています（末尾 §5 にトレーサビリティ表）。

## 1. メーカー側（maker）

> 画面：`/products/new`（登録）, `/maker/products`（自社資材一覧）, `/products/[id]/edit`（編集・削除）, `/maker/profile`（会社プロフィール）。

### M-1. 資材を新規登録できる

**前提**：maker でログイン済み。

**手順**
1. ヘッダーまたは `/maker/products` の導線から `/products/new` を開く。
2. 製品名（必須）を入力。一般用途・主成分・作用機序・販売状況（販売中/準備中/販売終了）を任意で入力。
3. 効果タグ・対象作目・認証を任意で選択。
4. 画像を1〜2枚添付（JPEG/PNG/WebP）。
5. 「資材を登録」を押す。

**期待結果**
- [ ] 登録成功後 `/maker/products` に遷移し、登録した資材がカードで一覧に出る
- [ ] 製品名未入力など必須エラー時は「製品名を入力してください」等のフィールドエラーが出て送信されない

`[ ] pass`　`[ ] fail`

### M-2. 登録直後は「非公開」で、owner ビューで自分は見られる

**前提**：M-1 を実施済み。

**手順**
1. `/maker/products` で登録した資材の詳細（製品ページ）を開く。
2. 別タブで未ログイン（またはログアウト状態）で、公開 `/products` 一覧・該当製造元ページを開く。

**期待結果**
- [ ] maker 本人は自分の非公開資材の製品ページを閲覧できる（owner ビュー）

**手順**

### M-4. 公開 / 非公開の切り替え（admin 連携の確認）

**前提**：M-1 の非公開資材がある。admin（AAL2）が使える。

**期待結果**
- [ ] 公開フラグを立てると、未ログインでも公開一覧・製造元ページに資材が出る
- [ ] 非公開に戻すと公開ページから消える

**期待結果**

**前提**：MFA 登録済みの admin。

**手順**

**期待結果**
- [ ] MFA 通過後に `/admin/reviews` に着地する

`[ ] pass`　`[ ] fail`

**前提**：farmer の pending レビュー（§2 F-3）がある。

**手順**

### A-3.【重点 / B1】承認済みレビューを「非公開化」→ 公開ページから消える

**前提**：A-1 で承認・公開済みのレビューがある。

**手順**
1. `/admin/reviews` の status フィルタを「公開済 (approved)」にして当該レビューを表示。
2. 当該行の **「非公開化」**アクションを実行（確認が出れば承認）。
3. 公開製品ページをリロード。
4. `/admin/reviews` の status フィルタを「却下 (rejected)」にして当該レビューを確認。

**期待結果**
- [ ] 【B1】非公開化すると公開製品ページから当該レビューが**消える**
- [ ] 【B1】admin 一覧で当該レビューの **status が rejected** になる（処理日時/理由「管理者により非公開化」が残る）
- [ ] 既に rejected のレビューに対する非公開化は冪等に扱われる（重複エラーで壊れない）

`[ ] pass`　`[ ] fail`

### A-4.【重点 / B2】ハード削除 → 一覧から消える & 画像も消える

**前提**：画像付きの不要レビュー（pending / approved / rejected のいずれでも可）を用意。**dev のみ**。

**手順**
1. `/admin/reviews` で対象レビュー行の **「ハード削除」**を実行。
2. 確認ダイアログ（`window.confirm`）で OK。
3. ページを再取得（リロード or フィルタ再適用）。
4. 当該レビューの製品ページを確認。
5. （可能なら）Supabase Storage `review-images/{user_id}/{review_id}/` フォルダを確認。

**期待結果**
- [ ] 【B2】ハード削除後、admin 一覧から当該レビュー行が消え、**再取得しても出てこない**
- [ ] 公開製品ページからも当該レビューが消える
- [ ] 【B2】Storage の当該レビュー画像フォルダが消える（best-effort。残存しても処理自体は成功＝200/204 で良い）

`[ ] pass`　`[ ] fail`
