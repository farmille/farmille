#### 自分を admin 化

Supabase Studio → Authentication → Users → 自分のアカウントを選択 → User App Metadata で:
```json
{"role": "admin"}
```

加えて SQL Editor で:
```sql
UPDATE public.users SET role = 'admin' WHERE id = '【自分の user_id】';
SELECT id, role, status FROM public.users WHERE id = '【自分の user_id】';
-- 期待: role=admin, status=active
```

#### pending メーカーを作る

シークレットウィンドウで `/signup` → `maker-pending@example.com` でサインアップ → onboarding 完了。Studio で:
```sql
SELECT u.id, u.role, u.status, mp.company_name
  FROM public.users u
  LEFT JOIN public.maker_profiles mp ON mp.user_id = u.id
 WHERE u.role = 'maker' ORDER BY u.created_at DESC LIMIT 5;
```
→ `status=pending_review` で登録されていれば OK（**ADR-0009 onboarding 修正の自動確認**）。

#### 既存 active maker

dev DB に既存テストメーカーがあればそれを流用。なければ別シークレットウィンドウで `maker-active@example.com` を作って、Studio から手動 `status='active'` に UPDATE。

   ```bash
   git push -u origin chore/sample-cta-withdrawal-cleanup
   git push -u origin feat/maker-approval-admin
   ```

3. レビュアー session で PR review
4. main にマージ → vercel.app に反映
