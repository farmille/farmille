# 画面の表記と投稿カード

## 表記

- 投稿は「実証詳細レポート」と「感想口コミ」に分ける。
- 資材の保存先は「お気に入り」とし、星のアイコンで示す。
- 資材の説明には「作用機作」を使う。
- 分類は「資材ジャンル（JBSA材料8分類）」とする。検索候補と絞り込みは `ingredient_categories` と `material_ingredient_categories` を参照する。検索クエリの分類名は `genre` とする。
- 資材ジャンル名（`name`）は分類に含まれる材料を読点で並べた長い名前なので、資材カードと資材詳細で資材名の上に添える資材ジャンルには略称（`short_name`、10文字以内）を出す。製品詳細の表、絞り込みの選択肢、比較表、管理画面には資材ジャンル名を出す。
- 退会した会員の投稿では、投稿者名を「退会済みユーザー」と表記する。
- 企業の会員（データ上は `seller_accounts`）は、画面と資料では「メーカー」と呼ぶ。
- メーカーの申請・運営の処理には「確認」を使う。
- 掲載する対象は「資材」、仕様・成分・使用方法などの情報は「製品情報」と呼ぶ。
- メーカーが資材ごとに取得する権限は「資材オーナー権限」、ログインに使うIDは「Farmille企業会員ID」と呼ぶ。
- プロフィールには「栽培作目」、投稿の入力欄と読み上げ用ラベルには「使用対象作目」を使う。
- 「終売表示」は資材ページを残して販売終了を示す。「非公開」は一般利用者が資材ページを閲覧できない状態を指す。
- 申請フォーム、受付票、メール、エラー文にも同じ用語を使う。受付票の項目名と選択肢名は現行の表記に揃える。
- メーカー名や資材名の横に、確認済みバッジやチェックマークを表示しない。
- 試験成績書などのPDFから実証詳細レポートの入力欄を埋める操作は「PDF読み取り」と呼ぶ。入った欄の印も「PDF読み取り」と表記し、「AI抽出」「自動入力」は使わない。PDFのどの試験を読むかを書く欄は「読み取る試験」と呼ぶ（「読み取る範囲」は使わない）。

## 投稿カードの操作

実証詳細レポートと感想口コミのカードには、左から「参考になった」、保存のブックマーク、閲覧数を並べる。閲覧数には目のアイコンを付け、右端に寄せる。

参考になったと保存には一般ユーザーのログインが必要となる。自分の投稿には参考になったを付けられないが、保存はできる。保存した投稿は、お気に入り画面の「保存した投稿」から開ける。

実証詳細レポートの閲覧数は詳細画面の閲覧を集計する。感想口コミはカードの操作行が画面内に入った時点で記録し、同じカードの表示中は重複記録しない。表示には `view_counts_total` の累計を使う。

## 保存データ

投稿の保存は `saved_posts` に記録する。1行につき感想口コミまたは実証詳細レポートのどちらか1件を参照し、ユーザーと投稿の組み合わせを一意にする。本人だけが一覧の取得・追加・解除を行える。追加できる対象は公開中の投稿に限る。

分類の出典：[日本バイオスティミュラント協議会自主基準（2025年9月8日）表1](https://www.japanbsa.com/standards/japanbsa-standards_20250908.pdf)。
