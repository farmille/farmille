# 完成見本の流用：決めたことの記録

完成見本（根本さん作の HTML、`farmille-demo/index.html`）の画面を本番アプリへ流用するにあたり、見本と本番の仕様が食い違った箇所と、その決定を残す。作業ブランチは `ui/mock-port`。

## 進め方

| 項目 | 決定 | 日付 |
|---|---|---|
| 画面の作り方 | 見本の CSS とHTML構造（クラス名）をそのまま流用し、固定データの部分だけ本番データに差し替える。既存部品を見本に寄せて作り直す方式は取らない | 2026-10-07 |
| 見本のスタイルの範囲 | 見本の画面だけに効くよう `.fm` の中に閉じる（`src/app/_mock/mock.css`）。サイト全体の色・書体トークンは変えない | 2026-10-07 |
| 見本にない画面 | 運営画面、パスワード再設定など見本にない画面は、無理に見本に寄せない（現状のまま） | 2026-10-07 |
| 動き・データ | 認証・権限・保存処理・DB は本番のまま。見本と食い違う場合も、決定するまでは本番の動きを残す | 2026-10-07 |
| 品質ルール | トークン経由の書き方と Storybook は、取り込み前にまとめて整える。型・ビルド・クライアントからDBに触れない、は最初から守る | 2026-10-07 |

## 資材ページ（`/materials/[id]`）

| 項目 | 見本 | 本番（流用前） | 決定 |
|---|---|---|---|
| お気に入りボタン（ログイン後） | 「☆ お気に入り」「★ お気に入り済み」 | 「お気に入りに追加」「お気に入りから解除」 | 見本どおり。読み上げ名は「お気に入りに追加／解除」を残し、`aria-pressed` で状態を伝える |
| お気に入りボタン（ログイン前） | — | 「ログインしてお気に入りに保存」 | 本番どおり（ログインへの案内として妥当） |
| 会社名の下の注記のリンク | 「企業会員登録」 | 「メーカー登録」 | 見本どおり「企業会員登録」 |
| 会社名の下の注記を出す条件 | メーカー未確認のときだけ | 常に表示 | 見本どおり。`materials.manufacturer_verified_at` が null のときだけ出す |
| 口コミの投稿者の立場（生産者など） | 表示する | 表示している（AGENTS.md の「立場は公開画面に出さない」と食い違い） | 表示する |
| お気に入り数 | 表示 | 数を出す仕組みがない | 当面「−」 |
| 製品詳細で中身が空の行 | 行ごと隠す | 「−」で出す | 未決（本番の「−」のまま） |
| 評価の分布 | ％ | 件数 | 見本どおり％（件数は読み上げに残す） |
| 関連する資材 | 「同じメーカー」「似た効果」の2種類 | 「同じ資材ジャンル」の1種類 | 未決（データは1種類だけ） |
