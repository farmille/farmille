| 項目 | 決定 | 日付 |
|---|---|---|
| 画面の作り方 | 見本の CSS とHTML構造（クラス名）をそのまま流用し、固定データの部分だけ本番データに差し替える。既存部品を見本に寄せて作り直す方式は取らない | 2026-10-07 |
| 見本のスタイルの範囲 | 見本の画面だけに効くよう `.fm` の中に閉じる（`src/app/_mock/mock.css`）。サイト全体の色・書体トークンは変えない | 2026-10-07 |
| 見本にない画面 | 運営画面、パスワード再設定など見本にない画面は、無理に見本に寄せない（現状のまま） | 2026-10-07 |
| 動き・データ | 認証・権限・保存処理・DB は本番のまま。見本と食い違う場合も、決定するまでは本番の動きを残す | 2026-10-07 |

## 裏側の追加が必要なもの

画面の流用だけでは実現できず、DB・サーバー処理の追加が要る項目。スキーマ変更を伴うため、画面の差し替えとは別のプルリクエストにする（AGENTS.md の規約）。

| 項目 | 必要な追加 | 状態 |
|---|---|---|
| レポートの「本名で投稿する」 | 投稿ごとの公開設定の列、本名（非公開の連絡先情報）を公開画面に出すときの取得経路と権限 | 未着手 |
| レポートの「一覧にない作物の自由記入」 | 作物マスタにない作物名を保存する列（またはマスタへの追加申請）と、提出時の検証 | 未着手 |

## 追加の決定（2026-10-07）

| 項目 | 決定 |
|---|---|
| 記事の「セクションを外す」 | なくてよい（使う場面がない）。裏側の追加の対象からも外す |
| レポートの注意書き（公開後の見え方・記事・資材ページの注記） | 方向は 2026-10-05 の方針（「保証しない」ではなく「条件によって変わる前提で見て」）。最終文言はオーナーが検討中のため、決まるまで見本の文言のまま |
| 見本の扱い | 見本は画面を見せるためのデモで、押しやすさのためにロジックを簡略化している。管理・編集・申請など機能の厚い画面は本番の作りを優先し、見本は見た目だけ当てる。製品情報の管理（/dashboard/materials/**）は見本に作り替えない |
| 使用目的の補足の保存方法 | 今は既存の保存関数を変えずに、下書き保存のあと purpose_note を別に書き込む形（提出は3往復で1トランザクションではない）。本来は保存関数（save_usage_report）に purposeNote を足す migration を別PRで入れるのが望ましい → 裏側の追加の候補 |
