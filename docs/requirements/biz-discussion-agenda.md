## 0. 議論の進め方

3. やるなら**期限**と**担当**
4. やるなら**必要な情報**（デザイン / コピー / 法務 等）

## 2. 議論項目

### A. コミュニティ機能 `/community` 🔥

**現状**:
- 既存 PRD §6: v1 やらない（リアルタイム更新系列）
- MVP: 4 グループのフォーラム形式で実装あり、投稿者・日時・投稿数を表示

**選択肢**:
1. **v1 で実装**: フォーラム/Q&A 系の業務フローを確定する必要あり（モデレーション・通報・荒らし対策）
2. **v1.5 に延期**: ローンチ後、コミュニティ需要をデータで見てから
3. **不採用**: そもそもレビュー単位の議論で吸収可能か

**決めること**:
- [ ] 実装する / しない / 延期
- [ ] 実装するなら、グループの「主体」は誰か（Farmille 運営 / メーカー / JA / 農家自治）
- [ ] 投稿は誰が書けるか（farmer/ja_staff/researcher のみ？ maker も？）
- [ ] モデレーション体制（手動 vs 報告ボタン）
- [ ] 通知機能（v1 にするか v1.5 か）

**関連**:
- §6 リアルタイム更新やらない決定との整合
- §8 v2 候補機能とロードマップ整合

### B. Farmille AI 🔥（納期確定）

**現状**:
- 既存 PRD §6: AI 構造化やらない（v2.5 候補）→ **v1 入り、6 月末納期に変更**
- MVP: ナビ項目あり、リンク先未確認

**決めること**:
- [ ] 機能の具体仕様の選択肢:
  - レビュー横断検索 AI（自然文クエリ → 該当レビュー）
  - 資材レコメンド（圃場条件入力 → おすすめ資材）
  - レビュー要約（製品ページに自動要約掲載）
  - Q&A エージェント（チャット形式）
- [ ] LLM プロバイダ（Anthropic / OpenAI / 内製）
- [ ] コスト負担（誰が払うか、メーカー有料化するか）
- [ ] データソース（既存レビューだけで十分か、追加データが要るか）
- [ ] ハルシネーション対策（出典明示、農薬規制系の誤情報リスク）
- [ ] アクセス制限（無料/有料、ロール別）
- [ ] UI: 独立ページ vs 既存ページに埋め込み

**緊急度**: 🔥 **6 月末逆算で 5 月初旬には spec 確定**したい

**関連 ADR 起票候補**:
- LLM プロバイダ採用判断
- LLM コスト管理（API 費用上限・キャッシュ）
- Farmille AI のデータパイプライン

### C. ランキング `/ranking` と `/leaderboard`

**現状**:
- 既存 PRD: 未記載
- MVP: BS 資材高評価 TOP 10 を ★評価軸で実装
- フッターに `/leaderboard`（人気ランキング）あり、`/ranking` との差分不明

**決めること**:
- [ ] `/ranking` と `/leaderboard` の差分（軸違い？同義？）
- [ ] ランキング軸（★評価 / レビュー件数 / 閲覧数 / お気に入り数 / 期間別）
- [ ] カテゴリ別ランキング（BS 分類別、作目別）の有無
- [ ] 表示件数（TOP 10 / 20 / 50）
- [ ] 不正対策（自社レビュー水増し、メーカー側不正）
- [ ] 「インセンティブ設計」（PRD §6 でやらない）との境界

**選択肢**:
1. **v1 軽量実装**: ★評価平均で TOP 10 のみ、シンプル集計
2. **v1.5 拡張**: カテゴリ別・作目別・期間別タブ追加
3. **不採用**

### D. メーカー公開ページ `/manufacturers`

**現状**:
- 既存 PRD: 未記載（メーカー側機能は `/maker/products` のみ）
- MVP: メーカー公開一覧/詳細を実装、ロゴ・社名・製品数・強み・所在地を表示

**決めること**:
- [ ] 公開項目（社名・ロゴ・所在地・連絡先・自社製品一覧・自社製品レビュー集計）
- [ ] メーカー側で編集可能な項目（プロフィール詳細）
- [ ] 検索/フィルタ（業種・地域・製品カテゴリ）
- [ ] 詳細ページの URL（`/manufacturers/{slug}` か `/manufacturers/{id}`、ADR-0006 整合）
- [ ] 検索エンジン公開可否（noindex の必要性）

**前提**:
- `maker_profiles` テーブル既存活用、軽量実装可能
- spec 先行起草に着手可（Ryoga 確認済み）

---

### E. URL 命名統一: `/products` vs `/bs-materials`

**現状**:
- 本リポ実装: `/products`（ADR-0006 URL 名前空間）
- MVP: `/bs-materials`（フッターには `/products` も併存）

**決めること**:
- [ ] どちらに統一するか
- [ ] 統一しないなら、両方サポートするか（リダイレクト戦略）
- [ ] ADR-0006 の改訂要否
- [ ] `/products/new` `/maker/products` との整合（メーカー側は `/products/*` のまま？）

**観点**:
- SEO（「BS資材」を URL に含めると流入に有利？）
- 国際展開時の英語 URL（`/products` の方が無難）
- ターゲット業界の検索クエリ（「BS資材 + 製品名」が一般的か）

### F. カテゴリ・作目ページ独立 `/categories` `/crops`

**現状**:
- 本リポ実装: `/products` 内の 3 階層作目カスケードフィルタとして吸収
- MVP: フッターに独立リンクあり

**決めること**:
- [ ] 独立ページを作るか、既存フィルタで吸収するか
- [ ] 作るなら何を表示（カテゴリ別/作目別の製品一覧・代表レビュー・SEO 用 LP）
- [ ] SEO 価値（カテゴリ別 LP が SEO 上で必要か）

### G. B2B ランディングサイト `/b2b/*`

**現状**:
- 既存 PRD: 未記載
- MVP: フッターからリンクあるが本体 `/b2b` は **404**
- フッターの想定リンク: `/b2b` `/b2b/features` `/b2b/pricing` `/b2b/register`

**決めること**:
- [ ] B2B LP を v1 に含めるか
- [ ] 含めるなら、料金プラン構成（無料/有料、機能差）
- [ ] メーカー登録の流入動線（`/b2b/register` → 既存 `/signup` への統合？）
- [ ] 「メーカー向け分析ダッシュボード」（既 PRD §8.11）と紐付けるか
- [ ] 営業チームの有無（問い合わせフォームの送り先）

### H. 静的ページ整備 `/about` `/contact` `/terms` `/privacy` 🔥

**現状**:
- 既存 PRD: 未記載
- MVP: 4 ページ実装あり

**決めること**:
- [ ] 各ページのコピー作成担当（biz 側 or 外注）
- [ ] **法務確認の要否**（terms / privacy は要法務レビュー）
- [ ] お問い合わせ `/contact` のフォーム送信先（メール? サポートツール?）
