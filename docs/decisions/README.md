# Architecture Decision Records (ADR)

プロジェクトの重要な技術的意思決定の記録。

## 命名規則
`NNNN-short-title.md` 形式。連番は4桁。

## テンプレート

```
# ADR-NNNN: タイトル

**ステータス**: Proposed | Accepted | Deprecated | Superseded
**決定日**: YYYY-MM-DD
**決定者**: 氏名

## コンテキスト
## 決定
## 理由
## 既知のリスクと対策
## 次回見直しタイミング
```
