# 資材の情報を読む

資材の特徴、利用者の感想口コミ、実証詳細レポートを読み、メーカー情報へ進む。

## Sub-features

- material-open：カードから資材詳細を開く。
- material-reviews：資材に紐づく感想口コミを読む。
- material-articles：資材に紐づく記事とレポートを読む。
- material-maker：メーカー情報を開く。

## How to get to it (user POV)

- 検索結果の資材カードを選ぶ。
- ホームの投稿に付いた資材リンク、マイページのお気に入り、メーカーの資材一覧から選ぶ。
- 詳細下部の関連資材から別の資材へ移動する。
- 共有された`/materials/<資材ID>`を開く。IDは表示中のリンクから取得する。

## Driving it with Codex Browser

前提条件：公開資材がある。検索結果のカード名とhrefをスナップショットで確認する。

- 詳細：`tab.playwright.getByRole("link", {name:観測したカード名, exact:true}).click()`を実行する。`/materials/`から始まるURLと同じ資材名を確認する。カードのアクセシブル名に説明が含まれる場合は観測したhrefでlocatorを絞る。
- 口コミ：詳細上の`/materials/<実ID>/reviews`を指すリンクをクリックする。「感想口コミ」の一覧、または投稿がない状態を確認する。
- 記事：詳細へ戻り、`/materials/<実ID>/articles`を指すリンクをクリックする。資材に紐づく記事やレポート、または空状態を確認する。
- メーカー：詳細のメーカー名リンクをクリックする。`/sellers/<実ID>`へ進み、メーカー名と資材一覧を確認する。
- 入口ごとにカード名、クリックしたリンク、到達URL、表示された資材名を記録する。

## Gotchas

- UUIDを推測しない。公開中のカードがない場合は前提不足としてskipする。
- メーカー未紐付けの資材はメーカーへのリンクがない。別の紐付け済み資材で確認する。
- 画像の外部CDNエラーと本文の取得エラーは別に記録する。
