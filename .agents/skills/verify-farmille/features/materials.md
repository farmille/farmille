# 資材の情報を読む

資材の特徴、利用者の感想口コミ、実証詳細レポートを読み、メーカー情報へ進む。

## Sub-features

- material-open：カードから資材詳細を開く。
- material-reviews：資材に紐づく感想口コミを読む。
- material-articles：資材に紐づく記事とレポートを読む。
- material-maker：メーカー情報を開く。

## How to get to it (user POV)

- 検索結果の資材カードを選ぶ。
- ホームの掲載資材（横に流れるカード）を選ぶ。同じ欄の「すべての資材を見る」は`/search`へ進む。
- マイページのお気に入り、メーカーページの「掲載資材」から選ぶ。
- 詳細下部の「関連する資材」から別の資材へ移動する。
- 共有された`/materials/<資材ID>`を開く。IDは表示中のリンクから取得する。

## Driving it with Playwright

前提条件：公開資材がある。検索結果のカードの資材名とhrefをariaスナップショットで確認する。

- 詳細：カードのリンク名には資材名のほかメーカー、評価、件数、分類なども入るため、資材名の完全一致では見つからない。観測したhrefで`page.locator('a[href="/materials/<実ID>"]').click()`を実行する。`/materials/<実ID>`へ進み、同じ資材名が見出しに出ることを確認する。
- 口コミ：詳細の「もっと見る（全N件）」（`/materials/<実ID>/reviews`）をクリックし、「感想口コミ」の一覧を確認する。0件のときはこのリンクが出ず、詳細に「まだ感想口コミがありません」が出る。
- 記事：詳細へ戻り、実証詳細レポート欄の「すべて見る」（`/materials/<実ID>/articles`）をクリックする。資材に紐づく記事やレポート、または「記事・実証詳細レポートはまだありません」を確認する。
- メーカー：詳細のメーカー名リンクをクリックする。`/sellers/<実ID>`へ進み、メーカー名と「掲載資材」を確認する。
- 入口ごとにカード名、クリックしたリンク、到達URL、表示された資材名を記録する。

## Gotchas

- UUIDを推測しない。公開中のカードがない場合は前提不足としてskipする。
- ホームの掲載資材は自動で横に流れ続け、Playwrightのクリックは位置が安定するまで待ち続ける。この入口は`browser.newContext({viewport:{width:375,height:812}, reducedMotion:"reduce"})`で流れを止めて操作し、流れる表示の確認とは別に記録する。
- メーカー未紐付けの資材はメーカーへのリンクがない。別の紐付け済み資材で確認する。
- 画像の外部CDNエラーと本文の取得エラーは別に記録する。
