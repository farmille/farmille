# Farmilleの機能マップ

各機能の入口と期待結果を検証する。375px幅、起動したローカルアプリ、Doctor成功を共通条件とする。認証が必要な機能には専用のテストユーザーを用意する。

| 機能                                  | 検証する内容                                 | データ更新     |
| ------------------------------------- | -------------------------------------------- | -------------- |
| [検索](search.md)                     | ホーム検索、資材検索、並び替え、空結果、解除 | なし           |
| [資材詳細](materials.md)              | 資材情報、口コミ一覧、記事一覧、メーカー     | なし           |
| [感想口コミ](reviews.md)              | 投稿、編集、削除、参考になった               | あり           |
| [お気に入りと比較](saved.md)          | 保存、保存一覧、比較、解除                   | あり           |
| [記事と実証詳細レポート](articles.md) | 種別切替、検索、本文、閲覧条件               | 閲覧条件に注意 |

同じ機能に複数の入口がある場合は、通した入口を明記する。1つの入口の成功をほかの入口へ拡張しない。今回変更した範囲に該当する入口をすべて通す。スキルの初回動作確認では1機能でよい。

`src/app/`には一般認証、メーカー、管理画面もある。この5機能の確認だけで全画面を検証したとは報告しない。対象が増えたらファイルを追加する。既存の広範な検証は`e2e/01-auth.spec.ts`、`e2e/03-usage-report.spec.ts`、`e2e/06-seller-approval.spec.ts`から`e2e/11-report-reading.spec.ts`を参照する。
