# 記事と実証詳細レポートを読む

記事一覧を検索し、記事や実証詳細レポートの本文を読む。

## Sub-features

- articles-type：コンテンツの種類を切り替える。
- articles-search：記事を検索する。
- articles-read：記事やレポートを開く。
- reports-access：閲覧条件に応じた本文と案内を確認する。

## How to get to it (user POV)

- メインナビの記事導線から`/articles`を開く。
- ホームの記事カードや実証詳細レポートから本文へ進む。
- 資材詳細や資材別記事一覧、メーカー情報から記事を選ぶ。
- 共有された`/articles/<実ID>`または`/reports/<実ID>`を開く。

## Driving it with Codex Browser

前提条件：公開記事または公開レポートがある。閲覧条件の確認では、未ログインと対象アカウントの状態をそれぞれ記録する。

- 種類：`tab.playwright.getByRole("tab", {name:"記事", exact:true}).click()`で記事だけに絞り、URLの`type=article`を確認する。「実証詳細レポート」では`type=report`、「すべて」では種別指定の解除を確認する。
- 検索：`getByLabel("記事を検索").fill(画面で確認した記事名)`の後に同じ入力で`press("Enter")`を実行する。URLの`q`と対象カードを確認する。一致しない文字列では「該当する記事・実証詳細レポートがありません」を確認する。
- 本文：表示カードのリンクをクリックし、見出しがカードのタイトルと一致することを確認する。戻っても検索条件が維持されることを確認する。
- 閲覧条件：レポートに案内が表示された場合は、その文言とログイン状態を記録する。`e2e/11-report-reading.spec.ts`と`src/components/ReportReadingGate.tsx`で対象状態の期待値を確認する。

## Gotchas

- 一般記事と実証詳細レポートで到達パスが異なる。
- 閲覧制限の案内を本文表示の成功に数えない。認証・閲覧条件を迂回しない。
- フィルターの実際のroleが変更された場合はDOMを読み直してから操作する。
